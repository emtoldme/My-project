# 可选调谐

基线 `1d56f45cb2f41f59e29e456ff0c86e55ba0f59a5`。分支 `gameplay/gp-b-objectives`。

GP00 还没有把共用类型放进仓库。这里没有复制草案里的 `ObjectiveSnapshot` 或 `ObjectiveRewardIntent`。宿主以后把下面两个入口接过去即可。

`TuningObjectives.Advance` 在玩家移动结算之后调用。暂停、升级或终局时 `Playing` 为假，或者直接把 `Dt` 传 0。死亡把 `Alive` 设为假。终局把 `Terminal` 设为真。锚点必须是已经校验过的坐标，这个模块不找 Transform。

`TryPeekReward` 只是查看同一张未兑现的单。`ConfirmReward(runId, objectiveId)` 成功一次就封账。旧的 `runId`、重复确认、还没完成，都不会再给第二次。

| 时刻 | 编号 | 请求的既有收益 |
|---|---|---|
| 2:30 | tune-1 | D02，回复 20% 最大生命，不提高上限 |
| 6:30 | tune-2 | D03，只吸场上已经存在的经验 |

范围是 2 米，按玩家中心判断，正好 2 米算在里面。站在里面累计 4 秒，走开只暂停，回来接着计。出现后 60 秒没完成就过期。两个都错过也不影响升级、精英或胜利。同一时刻如果又完成又死亡，不发奖。
