## 一、前期报告描述纠偏声明 (Correction of Premature Claims)

在深入分析 Codex 实际在 Unity 6000.4.3f1 环境中批处理生成的 `A01_AssetInspection.unity` 实机画面与 `import-report.json` 后，主美团队对前期文档（`A-R02`、`A-R03`、`A-R04`）中依据离线数据做出的“超前断言”做严肃的技术纠偏与定性校准：

1. **“零金属度”不等于“绝无塑料感”**：
   - 贴图通道实测数值为 0，只能在物理光照计算中证明其没有导体反射层；但在实机渲染下，材质高光的衰减形状（Specular Falloff）、法线平缓度及粗糙度均匀性若缺乏自然微起伏，依然可能在特定掠射角下呈现类似油蜡布或硬质塑料的平整感。
2. **“贴图均值对比”不能证明“预警可见度 100%”**：
   - 简单的 RGB 均值差异不能推导为复杂的战斗动态实况。若场景主光角度、Bloom 泛光、后处理 Tone Mapping 或阴影暗部交叠，朱红警示圈（`#FF3B30`）在深褐色麦田阴影处依然存在明度收缩风险，必须经过真实动态战斗实机检验。
3. **“源码含 instancing / 对象池代码”不等于“批处理与零 GC 实测达标”**：
   - 着色器包含 `#pragma multi_compile_instancing` 仅代表具备合批潜力；若材质属性未正确使用 `MaterialPropertyBlock` 或存在动态换材质行为，依然会打断 SRP Batcher。
   - `SonicAttackVFX.cs` 的 `Acquire` 当前采用的是**按需懒加载（Lazy Instantiate）**而非场景启动时全量预热，当突发高并发（如十连击）时依然会触发瞬时 GC 分配。
4. **声波特效暂无真实空间折射与模型撕裂**：
   - `ResonancePulseURP.shader` 本质是平面面片上的高频正弦发光干涉环，**未采样 `_CameraOpaqueTexture`**，并不包含真正的空间空气热浪/声波折射；
   - 敌人解体也未实现真正的 SkinnedMeshRenderer 顶点震荡，当前的震撼感主要源于麦草碎屑颗粒与色环，后续应如实定性。

## 二、“已观察 / 推断 / 待实机”四层视觉事实审查 (Four-Level Visual Assessment)

主美结合 `asset-inspection.png`、`foliage-closeup.png`、`weapon-closeup.png` 真实截图与资产数据，按四层事实严格划分：

### 1. 地面地表（Ground v0.2）
- **[已观察事实]**：
  在 `A01_AssetInspection.unity` 全景中，地表清晰呈现出干土碎石、密集麦草和踩踏泥土的自然质感；但是，三块材质以大矩形硬拼在一起时，**平铺周期纹样（Tiling Pattern）极为显著**，接缝处呈机械的直线生硬割裂，无法直接作为游戏关卡地面使用。
- **[推断]**：
  若在 60m 竞技场中使用单一材质拉伸平铺，玩家奔跑时会感受到强烈的网格重复感（Repetition Fatigue）。
- **[待实机验证]**：
  2 号在 RF01 中使用小路路径穿插与双材质（或三材质）自然过渡后，在 Orthographic Size 9.0、Pitch 55° 斜俯视移动镜头下的地表细节丰富度与辨识舒适度。

### 2. 立体麦田植被（Foliage v0.1）
- **[已观察事实]**：
  `foliage-closeup.png` 证实模型并非 2D 纸片，而是具备真实麦穗、麦芒立体结构的三维低多边形簇；但**单株麦丛（Wheat Cluster A/B）在独立摆放时偏单薄稀疏**，无法凭单一模型撑起“茫茫麦海”的感觉。
  此外，实测数据显示 **LOD1 比 LOD0 矮约 12% ~ 14%**（A: 1.99m -> 1.74m; B: 1.91m -> 1.65m），且麦芒轮廓收缩明显，若直接启用两级 LOD 切换，相机拉远拉近时会发生肉眼可见的“模型弹跳抽搐（Popping）”。
- **[推断]**：
  必须依靠高中低三级（2m 高麦丛 + 0.5m 麦茬残桩 + 0.25m 贴地野草）在受控密度与随机旋转（Yaw 0~360°）下组合重叠，才能构成厚实连绵的麦浪。
- **[待实机验证]**：
  在强制保持 LOD0 的情况下，200 株麦田在 GPU 顶点风动摇曳下的麦浪视觉连续性与阴影摆动流畅度。

### 3. 旧式声波调频器核心武器（Old Sonic Modulator）
- **[已观察事实]**：
  `weapon-closeup.png` 证实武器造型世界观冲击力极强，大口径黄铜喇叭、电木与铜线圈、双联发光电子管及模拟仪表盘在斜俯视角下轮廓分明；但同时暴露了**机箱侧面存在 UV 贴图拉伸变形**，且真空管玻璃外壳与橙红灯丝在正交俯视下的半透明折射质感较平，通透度仍显不足。
- **[推断]**：
  武器在主角手持状态下属于中景偏小物件，顶部仪表盘与橙色灯丝的微弱发光将成为识别主角射击姿态与方向的核心锚点。
- **[待实机验证]**：
  将武器 Prefab 放置于真实场景光照与地面背景上，观察在 55° 斜俯视视角下拉远至正常视距时，黄铜喇叭口与电子管灯丝是否依然清晰锐利。

### 4. 声波攻击视效（SonicVFX v0.1）
- **[已观察事实]**：
  命中效果采用了 `#B863A0`（迷幻紫红）加色共振环；而 M01-R1 机制试玩中，原目标的“二次回声（Echo）”同样是音波核心事件。若直接命中使用紫红大圆环，0.5 秒后的原目标回声爆发也使用类似紫红大圆环，在视觉语义上极易发生混淆，导致玩家误以为“直接击中就是回声”。
- **[推断]**：
  必须对“直接命中”与“延迟回声”施加严格的**色调分离与尺寸形体降级**：直接命中应收敛为极速暖白微爆与麦秸碎屑，而饱满的紫红色向心干涉环必须独家留给“0.5s 回声爆发”。
- **[待实机验证]**：
  Codex 将时钟与事件挂接至 M01-R1 后，双重反馈在同一敌人身上先后触发时的时间与视差清晰度。

## 三、给 2 号（场景装配）的具体建议（按优先级排序，严格限制 5 项）

请 2 号在构建 `Assets/Experiments/RyeField/` 下的 RF01 独立环境样板（`P_RF01_Environment.prefab` 与 `RF01_EnvironmentPreview.unity`）时，严格遵循以下 5 点：

1. **【优先级 P0】强制锁定麦丛使用 LOD0（禁用 LOD 跳变）**：
   - 鉴于 LOD1 存在 12%~14% 的高度收缩缺陷，当前 24m x 24m 的 RF01 样板中，所有生成的 `P_Wheat_A` 与 `P_Wheat_B` **必须在 LODGroup 中强制锁定渲染 LOD0（或禁用 LOD 切换）**，防止相机移动时麦田发生剧烈的上下跳变与穿帮，等待后续模型规范修复。
2. **【优先级 P1】确立中心战斗走廊的留白契约（半径 6m 严禁密植高麦丛）**：
   - 场景中心半径约 6m 的核心活动区域，**严禁散布 1.9m~2.0m 的高麦丛**；
   - 中心通廊只允许极少量点缀 `P_CutStubble`（0.5m 麦茬残桩）与 `P_WildGrass`（0.25m 贴地野草），确保玩家移动、敌人冲刺与地面朱红攻击预警圈（`#FF3B30`）100% 毫无遮挡。
3. **【优先级 P2】地表路径过渡（杜绝大方块硬接缝）**：
   - 24m x 24m 样板中，地表必须形成清晰的“踩踏小路（TrampledPath）贯穿麦田干土（DrySoil）”的有机走廊；
   - 严禁将三张材质以三个大方块硬拼在一起，应使用模块化网格拼接或带有平滑边缘过渡的面片组合，营造自然田间小径。
4. **【优先级 P3】高麦田采用三级错落编组（固定 Seed 20261012，总量 ≤ 300）**：
   - 在外围景观带，采用“高麦丛 A/B 作为主干 + 低矮断茬遮盖根部 + 野草点缀缝隙”的三级嵌套摆法，通过随机旋转（Yaw 0~360°）与微小缩放（Scale 0.85~1.15）消除单株稀疏感；
   - 严格控制 GameObject 总数在 **300 个以内**，严禁未经合批动态生成数千个对象拖垮编辑器。
5. **【优先级 P4】环境 Prefab 纯净独立性（无光照/相机/代码绑定）**：
   - 生成的 `P_RF01_Environment.prefab` 只包含地表 Mesh 与植被对象，**绝对不包含摄像机、平行光、GameLoop、战斗脚本或音效组件**，以便 Codex 后续将其作为背景一键挂入 M01 机制试玩场景。

## 四、角色原型（Protagonist & Scarecrow）入库现状与距可用差距清单

在 `SourceArt/Intake01/CharacterWIP/` 下，用户归档了主角与稻草人怪物的阶段性源文件（`Protagonist_Blockout_v01.blend`、`Scarecrow_v04_ArmRig.blend` 及多角度参考图）。

**主美严正定性**：上述资产目前处于 **白模拓扑与概念草稿阶段（WIP）**，绝不可作为正式角色合入游戏工程，严禁用简陋方块假冒正式角色达标！

距可导入 Unity 实机的核心差距清单如下：

| 评估维度 | 主角白模 (`Protagonist_Blockout_v01`) 差距 | 稻草人敌人 (`Scarecrow_v04_ArmRig`) 差距 |
| :--- | :--- | :--- |
| **网格拓扑 (Topology)** | 处于粗模 Blockout 阶段，缺少面部、衣褶与机械关节布线；未进行肢体解耦与面数优化。 | 仅具备基础躯干与手臂分支，关节处缺乏形变环线（Loop Cut）。 |
| **骨骼与绑定 (Rigging/Skinning)** | **完全无骨骼（No Armature）**，无法绑定动画；缺少手部持枪挂点（Weapon Socket）。 | 仅具备单臂基础骨架测试（ArmRig），**缺乏完整人形骨架与蒙皮权重（Weight Painting）**。 |
| **动画片段 (Animation Clips)** | 无任何动作片段；缺少 Run、Idle、Dodge（闪避翻滚）及 Shoot 基础骨骼动画。 | 缺少 Crawl、Attack、Stun、Death 等敌人必备战斗动作。 |
| **UV 与材质 (UV & Texturing)** | **未展 UV，无 PBR 材质与贴图**；当前仅为 Blender 纯色材质槽，导入 Unity 会呈现粉色或纯白。 | 无贴图图集，布条与稻草纹理尚未烘焙。 |
| **武器持握契约 (Holding Socket)** | 尚未确定双手骨骼与 `Old Sonic Modulator` 握把的适配吸附点。 | 无受击盒（Hitbox）与受击闪烁（Flash）通道规范。 |

**后续行动建议**：
角色与怪物目前继续停留在 `SourceArt/Intake01/` 归档；当前阶段 M01 与 RF01 继续复用既有的测试胶囊体/基础人形代理。待用户或外部建模完成骨骼蒙皮与行走/持枪动作导出为 FBX 后，再正式启动角色美术接入流程。
