   - 主美不凭空制作批量正式资产充数；

## 二、给 2 号（E-01 实验）的精简资产接入规格清单

为确保后续用户提供的正式资产以及 2 号当前的技术实验能够无缝装配至 Unity 6 URP，制定以下技术规格契约：

### 1. 尺度、单位与轴向契约 (Scale, Units & Orientation)
- **绝对单位**：`1 Unity Unit = 1.0 Meter`（1 米）。严禁在 FBX 导入或模型根节点出现 100 倍或 0.01 倍缩放传递至表现代码。
- **朝向规范**：正前方严格为 `+Z` 轴，竖直朝上为 `+Y` 轴，右方为 `+X` 轴。
- **轴心位置 (Pivot)**：
  - 角色/敌人/可移动机械：**脚底与地面接触面的水平投影几何中心**为原点 `(0, 0, 0)`。
  - 建筑/大型农机（如联合收割机、粮仓）：**基底中心**为原点 `(0, 0, 0)`。
  - 模块化地面地块：**地块顶面几何中心**为原点 `(0, 0, 0)`。
- **俯视基准尺度**（在 Orthographic Size 9.0、Pitch 55° 斜俯视镜头下）：
  - **主角（人类/乡村修理工）**：高度基准 **1.75m ~ 1.85m**，肩宽约 0.55m ~ 0.65m（当前镜头下约 55~65 屏幕像素）。
  - **小型/普通敌人（异常农械/感染体/飞虫群）**：高度 **1.2m ~ 1.5m**，外径 0.8m ~ 1.1m。
  - **大型/精英敌人（失控重型农机/广播异化构件）**：高度 **2.5m ~ 3.5m**，占地 2.5m x 2.5m。
  - **环境障碍物（锈蚀拖拉机、木栅栏、电线杆）**：栅栏高 1.1m，拖拉机高 2.2m，电线杆高 6.5m。

### 2. 节点层级与 Prefab 契约 (Hierarchy & Socket Structure)
为保证 1 号规则逻辑（位置、位移、碰撞体）与表现动效彻底解耦，要求 Prefab 必须具备统一节点结构：
```text
[Prefab Root] (挂载碰撞体 Collider、逻辑标识，Transform 严格保持 Pos: 0, Rot: 0, Scale: 1)
 └── MotionRoot (表现位移与受击回弹承载节点)
      ├── VisualMesh / SkinnedMesh (实际几何体渲染节点)
      ├── Sockets (功能挂点)
      │    ├── Muzzle_Socket (武器/声波发射源点，向前方 +Z 偏移)
      │    ├── Hit_Socket (受击粒子与闪白中心)
      │    └── Overhead_Socket (血条、状态与警示图标挂点)
      └── StatusFX (挂载本地粒子或光环，随 MotionRoot 运动)
```

### 3. URP Stylized PBR 材质与贴图通道规范 (Material & Texture Pipeline)
项目采用 URP 内置 Lit 着色器（或基于 Lit 扩展的轻量 ShaderGraph）：
- **去油腻核心法则**：
  - **非金属主体物理起点**：人类皮肤、衣物帆布、泥土、生锈铁皮的非金属区域，`Metallic` 严格初始为 `0.0`。严禁全场统一赋予中等金属度导致油亮发光。
  - **粗糙度映射**：传统 PBR 贴图中的 Roughness 通道在导入 Unity URP 时，必须取反（`Smoothness = 1.0 - Roughness`）。
  - **平滑度阶梯**：
    - 泥土地面/木板/枯草：`Smoothness: 0.10 ~ 0.22`（绝对哑光）；
    - 锈蚀机械外壳/磨损涂漆：`Smoothness: 0.25 ~ 0.40`（漫光散射）；
    - 裸露摩擦金属/旧挡风玻璃：`Smoothness: 0.60 ~ 0.80`（局部微高光）；
    - 水洼/潮湿地面：`Smoothness: 0.85 ~ 0.95`（仅限于特定浅坑，不全场平铺）。
- **标准贴图打包格式（ORM 规范）**：
  - **BaseColor (RGB) + Alpha**：sRGB 格式，色块干净，避免在 Albedo 贴图上直接烘焙高光污渍；
  - **Normal Map (RGB)**：Normal Map 格式，用于表现农机冲压接缝与铁板铆钉；
  - **Mask Map / ORM (RGBA)**：Linear 格式（关闭 sRGB）：
    - R 通道：`Occlusion`（环境光遮蔽 AO，用于凹槽接触阴影）；
    - G 通道：`Roughness` 或 `Detail Mask`；
    - B 通道：`Metallic`（金属度遮罩）；
    - A 通道：`Smoothness`（平滑度通道）。
  - **Emission (RGB)**：用于模拟信号灯、电子仪器面板、发光异常核心。

### 4. 字体与 UI 美术规范 (Typography & UI Assets)
- 界面技术统一基于 **uGUI + TextMeshPro**；
- 字体要求：采用具有 1980 年代模拟收音机、仪表盘及复古打字机特征的无衬线等宽/工控字体（如 DIN、Share Tech Mono 或其开源替代品）；
- 涉及中文字体时：必须提供开源商用许可（如思源黑体/思源宋体衍生风格），且必须预先生成 TextMeshPro Font Asset（SDF 贴图），不得依赖运行时系统字体动态回退。

## 三、色彩叙事与战斗辨识技术约束 (Color Narrative vs. Combat Readability)

《麦田里的混响》核心美学确立了四种具有浓厚叙事隐喻的色彩：
- **黄色（现实/土地/麦田）**
- **红色（历史/牺牲/抵抗）**
- **蓝色（未来/技术/控制）**
- **品红色（干涉/反抗/迷幻声波）**

### 硬性技术约束（防止叙事色彩破坏玩法可读性）：
1. **严禁敌我同色混淆**：
   - 尽管“黄色”是麦田的主色调，但环境麦田必须采用**低饱和度、偏暖褐与泥土调的干枯金黄**（如 `#C29B38` / `#8C6D2D`，明度控制在 40%~60%）；
   - **经验/生命道具黄色**：必须采用**高明度、带金属光泽的鲜艳亮金**（`#FFD700`），辅以小范围垂直脉冲，与地表形成明度反差（ΔValue ≥ 40）。
2. **危险预警（AOE / 冲刺红线）必须拥有最高视觉特权**：
   - 红色在叙事中代表历史与第四粮仓，但在战斗实时反馈中，**朱红/血橙色（`#FF3B30` / `#FF4500`）是全场唯一的危险警示色**；
   - 场景中代表历史的红色物体（如锈红粮仓墙体、红色农机残骸）必须做**老化、灰度衰减处理**（暗砖红 `#6E2620`，无自发光）；
   - **敌人攻击预警红圈/轨迹线**：必须具备动态 Alpha 扫掠或外边框高亮，亮度达到 HDR x2.0，确保在红砖或土地上依然清晰可见，严禁被场景红混淆。
3. **玩家与友方信息锚定**：
   - 玩家角色在暗调/暖调乡村中，外形需具备**冷色高对比度焦点**（如老式深蓝夹克配合高亮米白头盔/反光条，或广播接收器的冷青色背光指示器）；
   - 玩家射弹与闪避声波：采用**激光青蓝（`#00E5FF`）与前期微弱品红（`#E024C3`）**，与敌方攻击严格区分。
4. **品红色（Magenta）的克制与分级**：
   - 品红色代表时间干涉与终极声波，属于高级/爆发视觉能量；
   - 在 S1~S2 基础战斗中，品红色仅允许出现在**玩家特定机制装备爆发（如回声连锁、过载脉冲）**的瞬间；
   - 严禁全屏铺满品红雾气或全屏色差（Chromatic Aberration），透明粒子半透明重叠层数严控 ≤3 层，避免遮挡地面危险提示超过 0.2 秒。

## 五、2 号 E-01 实验的艺术审查维度与标准 (Review Criteria for E-01)

当 2 号完成 `experiment/e01-asset-wave` 分支并交付截图与测试场景后，主美将依据以下双轨标准进行严格审查：

### 1. 技术接入正确性（Pass / Fail）
- [ ] 模型是否有且仅有一套根节点缩放（严格为 1, 1, 1，无导入 100 倍形变）；
- [ ] 轴心是否位于脚底中心；
- [ ] 材质是否为标准 URP 材质，有无 Shader 丢失或粉红错误；
- [ ] 触发 Shot / Hit 时声波 Mesh / 粒子的生命周期是否正常，暂停时是否冻结，重开时是否完全回池清理；
- [ ] 画面有无出现同类 FX 叠播或 DrawCall 激增。

### 2. 艺术表达成熟度（合格 / 待制作）
- [ ] **允许技术通过但艺术待制作**：明确记录“技术通路已打通，但模型为占位几何体，正式质感待用户提供模型”；
- [ ] 检查声波环材质是否具备物理厚度与切片衰减，是否避免了大面积 Bloom 泛白；
- [ ] 检查是否遵循了去油腻法则，地面高光有无刺眼白斑。

本清单将作为后续审查 E-01 实验交付物的硬性依据。
