## 一、一页纸资产接入技术检查表 (One-Page Asset Ingestion Checklist)

| 校验类别 | 审查项 (Check Item) | 规范标准与硬性指标 (Specification) | 判定 (Pass/Fail) | 责任说明 |
| :--- | :--- | :--- | :--- | :--- |
| **几何与尺度** | **世界根单位** | `1 Unity Unit = 1.0m`；Gameplay 根节点 Scale 必须保持严格 `(1.0, 1.0, 1.0)` | 必须通过 | 严禁将 FBX 的 100x 或 0.01x 传递给规则代码与残影 |
| | **朝向契约** | 正前方严格为 `+Z` 轴，竖直朝上为 `+Y` 轴，右方为 `+X` 轴 | 必须通过 | 配合 GameLoop 射击与朝向计算 |
| | **轴心 (Pivot)** | 角色/敌人/移动机械脚底贴地投影中心为原点 `(0, 0, 0)`；建筑为底座中心 | 必须通过 | 保证出生与地面贴合，无半截入地或浮空 |
| | **角色尺度** | 主角视觉高 **1.75m ~ 1.85m**；普通敌人高 **1.2m ~ 1.5m**；大型/精英高 **2.5m ~ 3.5m** | 提案基准 | 允许通过 Visual 子节点挂载并做局部受控缩放适配 |
| **节点与层级** | **逻辑与动效解耦** | 根节点挂 Collider/规则句柄；子级挂 `MotionRoot` 承载回弹/动效 | 必须通过 | 严禁动效 Tween 或动画直接修改根 Transform |

## 二、结合 E-01 实际运行截图的审查与事实定性 (Review of E-01 Verification)

基于 PR #20 中合并的 Unity 6000.4.3f1 / URP 17.4.0 实际运行事实（`Docs/Verification/Reverb-Experiments-01/` 及 `Assets/Experiments/VisualPipeline/`）：

### 1. 技术接入事实复核（PASS）
- **模型与尺度适配**：
  - 依据 `E01_IMPORT_FACTS.txt`：第三方资源 `George.fbx`（Quaternius）原始 `fileScale=0.01`、`bounds=(4.77, 7.77, 5.75)`；
  - 2 号通过在 `Visual` 子节点应用 `(0.23, 0.23, 0.23)` 缩放与 `boundsAfter: (1.11, 1.80, 1.33), minY=0` 成功落地，`PlayerRoot` 保持绝对 `(1.0, 1.0, 1.0)`。**证明了受控适配层的工程有效性，无需强行修改第三方 FBX 导入设置**。
- **声波网格与粒子表现**：
  - 依据 `e01-runtime.txt`：`Real shots=1, hits=1, rendered ring pixels=1447`；
  - 依据 `e01-wave-on.png` 与 `e01-wave-off.png` 像素比对：在 Orthographic 55° 斜俯视视角下，声波 Mesh 环成功渲染并呈现了 1447 像素的可见覆盖差异；
  - 暂停冻结、重开清理完全通过，且由独立的 Unity ParticleSystem 替代了初期的方块备选。
- **URP 兼容性**：
  - 自定义 ShaderGraph（`E01_WaveRing.shadergraph`）成功经由反射生成与绑定，Alpha Clip 生效，无渲染报错与粉红 Shader 丢失。

### 2. 艺术表达成熟度事实定性（DEFICIT / PENDING USER ASSETS）
对照 `e01-wave-on.png` 画面进行客观艺术审查：
- **画面仍属纯技术占位，未脱离灰盒状态**：
  - **角色与敌人**：场景中依然为旧工业机甲（`George` 与 `Mike`），不具备《麦田里的混响》1988 美国乡村、工装夹克、无线电背包或异化农机的任何视觉元素；
  - **地面与环境**：地面为单调无细节的 60m x 60m 纯色测试方块，完全缺乏麦田、干燥泥土、车辙或秋季植被特征；
  - **声波与光影**：声波环当前为测试青色双面 Alpha Clip 环形贴片，尚未融合迷幻音波的微衰减与粒子散射；环境缺少定向主光投射的接触硬阴影。
- **审查结论**：  
  **【技术通路已验证通过，艺术资产处于完全占位状态（TEST_ONLY）】**。  
  该实验成功证明了 URP 管线、多网格适配与事件驱动特效的可靠性，但**绝对不能被误认为正式乡村画面已达标**。后续正式艺术质感必须在用户交付指定模型与贴图后再行评估。

## 三、四色叙事与战斗辨识技术提案（参数化建议，非强制常数）

为防止未来正式美术接入时“叙事用色与战斗提示相撞”，将四色设计原则明确为**面向策划与装配的建议区间**：

```text
[叙事背景层 (低饱和/高衰减)]                   [战斗交互层 (高对比/优先特权)]
---------------------------------------------------------------------------------
麦田/土地: 干燥金黄/泥土棕 (#8C6D2D ~ #C29B38)   --> 经验/生命掉落: 高亮亮金 (#FFD700), ΔV ≥ 40
历史建筑: 暗砖红/锈蚀粮仓 (#6E2620, 无自发光)      --> 危险/AOE 预警: 朱红/血橙 (#FF3B30, HDR x2.0)
异常控制: 广播塔冷灰/冷调夜幕                     --> 玩家信息焦点: 激光青蓝 (#00E5FF, 常驻视窗)
时空干涉: 局部环境色偏                           --> 机制爆发能量: 迷幻品红 (#E024C3, 限爆发时段)
```

1. **绝对特权原则**：朱红/血橙预警线拥有全场最高渲染优先级，不受场景建筑贴图干扰；
2. **品红克制原则**：品红粒子重叠严控 ≤3 层，半透明衰减生命周期 ≤0.25 秒，禁止全屏色差干扰。
