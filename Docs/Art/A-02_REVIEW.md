## 二、实机画面五项核心审查与低成本修正建议

对比 `scene-preview.png`（正式灰盒）与 `Art_GameView_IndustrialMech_1080p.png`（独立测试场景），提出以下无需推翻重做、极低改造成本的调优建议：

### 1. 玩家 / 敌人 / 地面的明度层次与对比度（Luminance Hierarchy）
- **实机现状诊断**：
  - `scene-preview.png` 中地面整体灰度均值约为 72，玩家机甲区域均值仅为 36~43，**玩家整体偏暗，未能成为第一视觉焦点**。
  - 玩家 `George` 的深色机械结构与灰色混凝土地面产生黏连，在 55° 斜俯视正交视角下，缩放或暗光时轮廓不够一目了然。
- **低成本修正建议**（交付 2 号或后续装配）：
  - **地面调暗/拉开基底**：在 `M_Precast_Concrete.mat` 中，将 `_BaseColor` 适度微调至更深沉的冷岩石墨色（从 `(0.25, 0.28, 0.33)` 调降至 `(0.18, 0.20, 0.24)`），为全场角色让出明度空间。
  - **玩家提亮与色阶分离**：在 `M_Player_HeavyMech.mat` 中，将 `_BaseColor` 乘以 `1.25`，强化灰白装甲板的受光面反射（提高到 0.85 浅灰白），确保玩家在纯黑白灰度图下与地面的明度差 `ΔValue ≥ 40`。

### 2. 贴图复杂度与外轮廓可读性（Texture Noise vs. Silhouette）
- **实机现状诊断**：
  - Quaternius 机甲自带的漫反射贴图（如 `George_Texture.png`）存在较多军工迷彩线条与杂色噪波。
  - 在正交俯视镜头（距离地面约 25m）下，表面细碎线条不仅无法被肉眼有效识别，反而切割了机体原本硬朗的倒梯形外轮廓。
- **低成本修正建议**：
  - **轮廓大于贴图**：材质不要依赖漫反射贴图里的画笔阴影。在材质球中保持 `_Smoothness` 在 0.40~0.48 之间，通过 Unity URP 主太阳光的软阴影投射和边缘倒角来交代硬表面结构。
  - 后续若定制抽象几何模型，直接使用干净的纯色分色块（Clean Color Blocks），彻底剔除碎碎的破损贴图。

### 3. 局部强调色与光学标识（Local Accent Colors）
- **实机现状诊断**：
  - 目前所有机甲材质的 `_EmissionColor` 均处于默认关闭/黑色状态，仅在受击时通过脚本触发闪白。
  - 导致在常态巡航与瞄准过程中，玩家缺少明确的“主控感”指示，敌人也缺少“威胁感”光标。
- **低成本修正建议**：
  - **方案 A（无需任何贴图，零改动最简方案）**：在玩家机甲预制体（`Player_George_Visual.prefab`）的头部相机传感器挂点，挂载一个微型发光几何 Quad（0.2m x 0.2m，直接使用已有的 `M_FX_Muzzle_Cyan` 材质）。在 55° 俯视下，青蓝发光点将作为玩家移动的永久视觉准星。
  - **方案 B（使用已交付的遮罩）**：2 号可直接在 `Assets/Art/A02/` 提取已生成的 `George_Emissive_CyanMarker.png` 赋予材质的 `_EmissionMap`，开启局部自发光。

### 4. 哑光层次与去油腻（Matte Hierarchy）
- **实机现状诊断**：
  - 当前两张实机截图中，地面均值控制在 75~80，未出现大面积镜面反射白斑，去油腻原则基本守住。
  - 但目前所有物体（墙体、柱子、箱子）的粗糙度非常接近（0.38~0.48），导致画面略显扁平，缺乏材质层级区分。
- **低成本修正建议**：
  - 建立明确的**三级哑光阶梯**：
    1. **第一级（绝对哑光）**：地面 `Smoothness: 0.22, Metallic: 0.05`，吸光且平整；
    2. **第二级（半哑光装甲）**：机体面板与场景建筑 `Smoothness: 0.40, Metallic: 0.25`，柔和散射漫光；
    3. **第三级（局部高光点）**：仅核心武器枪管与传感器小构件 `Smoothness: 0.85, Metallic: 0.80`。

### 5. 动效语法与战斗爆发感（Burst Readability）
- **实机现状诊断**：
  - S1 现阶段闪避仍为位置突变（占位阶段），受击闪白由 VfxDirector 驱动。
- **低成本修正建议**：
  - 闪避残影使用 `M_FX_Afterimage`（半透明青蓝），持续时间保持在 `0.15s` 极速衰减，严禁残留堆积；
  - 保持受击闪白只有 0.06s，保证敌人受到连续攻击时不会永久处于过曝白色状态。

## 三、风格取舍对比：工业机甲 vs. 抽象几何雕塑

为了让用户能够在看清实际材料后做出明确判断，准备了以下同机位/同环境下的**两组风格方向对比**：

### 组 1：实机渲染现状对比（真实引擎截图）

| 视角/维度 | 方案 A：工业写实机甲（当前 S1 临时素材） | 方案 B：抽象几何/干净色块雕塑（目标方向） |
| :--- | :--- | :--- |
| **参考图片** | 实机截图：`Assets/Art_GameView_IndustrialMech_1080p.png` 与 `Docs/Verification/P-01/scene-preview.png` | 概念草图与目标图：`S1_Resonant_Sculpture_Visual_Target.png` |
| **本质属性** | **实际 Unity 6 引擎实机抓取截图**（1920x1080 / 1280x720，含真实 URP PBR 光照与软阴影） | **设计参考与视觉目标概念图**（展示设计意图，非引擎运行实机） |
| **形体特征** | 具象机械细节、活塞、履带/关节、传统机甲科幻外壳 | 纯粹的 45° 倒角多面体、非对称偏心悬浮分节、几何极简切面 |
| **色彩质感** | 迷彩灰绿/战术深灰、带细微接缝与风化噪波 | 哑光陶瓷白、深石墨黑、局部激光青蓝/朱橙冷暖强烈对比 |
| **优势与代价** | **优势**：有现成 CC0 资源包，S1 落地速度最快。<br>**代价**：细节碎，远距离俯视辨识度依赖写实机械纹理，缺少极具标志性的独特视觉符号。 | **优势**：与数学摇滚/电子音乐高度契合，视觉极为干练冷静，同屏 200 敌群依然轮廓清晰。<br>**代价**：需要针对性定制或二次精简模型，属于后续阶段迭代目标。 |

### 组 2：俯视辨识度与战斗信息对比

| 审查要点 | 方案 A：工业机甲（现有素材） | 方案 B：抽象几何雕塑（目标意图） |
| :--- | :--- | :--- |
| **小剪影辨识度** | 依赖双足、四足肢体外伸形态区分敌人；肢体交叠时局部混乱 | 依靠巨大的几何切面与特征倒角（立方体/金字塔/菱形），轮廓极强 |

| **爆发动效契合** | 传统机甲开火、后坐力、常规机械运动 | “错位、分节弹开、悬浮复位”，动作带有切分节拍感，与音效完美共鸣 |
