# 立体麦田 R5

2026-10-14。按用户要求把实际 Main 中的麦子从交叉透明贴片换为立体模型，并接入麦浪和薄叶逆光透光。本轮基于 HC02，不修改战斗、成长或存档规则。源码分支 `art/volumetric-wheat-r5`。

## 模型与实际接入

新增四种麦株变体，每种有三级模型：近处三根分蘖、分粒麦穗、细麦芒和带中脊的卷叶；中景两根分蘖和简化实体麦穗；远景单根分蘖及实体穗体。麦秆与穗粒有立体截面，叶片是弯曲的薄表面，普通植株不依赖透明图集或朝向相机的平面。远景仍为几何模型。

每个近景模型453顶点/486三角形，中景90/114，远景28/35。资源在 `Assets/Game/Art/VisualIdentity/WheatR5`，生成源为 `WheatGeometry.cs`。原 RyeCard 与图集保留，但 Main 运行时及新编辑预览不再使用它们。

沿用R4的24米地块与默认49块回收池。植株散布为每块26×26个候选位置，按既有地形/道路/收割/倒伏/兴趣点空地采样筛选。默认近处9块使用详细模型，中间16块简化，外圈24块使用远景模型；移动后每帧最多补一块或重建一块细节，优先补齐新地块及近处细节。各级使用相同候选坐标、变体和缩放，不生成植物碰撞体。

Main序列化引用新材质和12个模型资产，着色器随构建收录。旧编辑麦田组停用并保留，新 `WheatFieldPreview` 使用同组模型做编辑预览，运行时由流式麦田接管。手工画完Terrain道路后，原“Reverb → 更新植被遮罩”也会刷新模型预览。

## 风与光

`Reverb/Volumetric Wheat` 不采样旧麦子透明图集。风相位读取世界坐标，长距离风阵叠加细摆形成跨地块的连续波前；根部固定，越向穗顶弯曲越明显，叶尖与芒尖有小幅颤动。雨天读取既有天气风强增强摆幅。时间来自 `RunSimulation.State.Now`，出发前、暂停、升级和日志冻结时停止。

透光采用按表面厚薄区分的背光近似：叶片和麦芒最透，麦穗较厚，麦秆较弱；这是光穿过薄表面的暖色散射效果，植株本身仍为不透明几何。没有实现体积多次散射或真实厚度求解。干叶尖略偏金，成熟度变化与雨中颜色变深沿用既有地图和天气输入，不添加材质自发光。

主光、农机/路灯等局部光、阴影与雾进入同一着色。Forward、ShadowCaster、DepthOnly及DepthNormals共用变形和玩家附近的裁切；阴影使用URP的偏移与近裁切函数。弯曲法线使用近似旋转。保留玩家周围压低/整株淡出，以及最多8个附近真实掉落物的压低区域。

可调参数：

| 位置 | 参数 | 作用 |
| --- | --- | --- |
| WheatVolume.mat | WindStrength | 默认0.24，控制弯曲角度 |
| WheatVolume.mat | WindSpeed | 默认1.1，控制成片波前速度 |
| WheatVolume.mat | Transmission | 默认0.9，控制薄叶与芒的背光强度 |
| WheatVolume.mat | Stem/Leaf/Ear/Transmission Color | 麦秆、叶片、麦穗、过滤光颜色 |
| Main的GardenWeather | windStrength / F6天气 | 风雨增强与原天气切换 |
| Main的ProceduralFieldStreamer | worldSeed / randomizeSeed / loadRadius | 地图复现与驻留范围 |

## 定向验证

只验证本次麦田模块。13项安装检查覆盖12个模型的空间体积和着色器导入；16项真实Main检查覆盖正式出发、序列化引用、49块回收预算、三级细节数量、无植物碰撞、阴影接入、每顶点根部数据、游戏时钟、暂停冻结、雨中增幅、负坐标两公里探索、细节随探索更新及活动着色器无错误。未重跑整局或全面帧率矩阵。

本次种子14104，累计生成122块，驻留始终49块；出生区驻留3,361,962顶点/3,808,278三角形，远处3,006,952/3,422,090。这是整个驻留池的几何数量，包含屏外地块，不能据此宣称具体帧率或所有设备性能达标。

实际Main摄像机的1920×1080图像保存在上级 `Reviews/WheatVolumeR5-2026-10-14`：`main-golden-field.png`、`wheat-volume-close.png`、`wheat-wave-later.png`、`wheat-rain.png`、`wheat-far-world.png`。逆光对照 `wheat-transmission-off/on.png` 在暂停姿态下改变透光参数，开关比较约41万像素有超过3级RGB变化，开启后全图平均R/G/B增加4.48/2.07/0.34；近景检查临时调整了太阳方向，未写回默认场景。截图为显式渲染实际摄像机，省略OnGUI界面。最终实景日志为 `play-camera-review.log`。前两次采图脚本的后台截图等待/暖机帧数问题保留在早期日志，不作为通过证据；既有编辑器插件日志噪声不属于麦田模块。
