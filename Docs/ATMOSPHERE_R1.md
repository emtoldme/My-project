# 氛围R1：雨后黄昏

2026-10-13。根据用户最新反馈，暂停继续打磨幸存者玩法，把现有规则作为可移动、可战斗的基底，优先画面、氛围与动效。本轮是视觉迭代，不代表画质验收完成。

## 这一版的变化

- 从正交俯视改为42°视场的透视镜头、43°俯角，加入轻微的移动前瞻、后坐和受击/闪避冲击。镜头保持固定朝向，移动方向仍由真实相机计算。
- 陶瓷漆面、裸露金属、黄铜氧化层、石墨结构分别使用不同的粗糙度和金属度。新增世界空间风化与微表面起伏，降低整片表面的湿亮高光；地面保留局部积水的高光，普通湿土更粗糙。
- 冷色环境光与较暖的局部灯形成层次。三处局部灯光雾束按16步采样，并通过相机深度截断；这是有限局部体积近似，没有引入全场体积雾框架。低层漂雾改为噪声软边，避免纯白圆片。
- 麦浪改为宽尺度阵风，加入逆光透射与玩家附近柔和弯折；四面旧信号布依照局内时钟摆动，灯具增加外壳与下垂电缆，悬吊结构转动放慢。
- 走动按实际位移发出踩水涟漪或干尘，实际命中发出短寿命碎光与近距离瞬时灯光，角色有克制的刚体后坐与倾斜。新增表现只读事件和位置，不扣血、不改变敌人AI或奖励。
- 界面底色更轻，危险填充降低透明度；F8切换观景，隐藏HUD但继续更新危险与规则。F6继续切换天气，F11切换全屏。

## 资源与预算

复用现有角色、麦田图集与来源资产；本轮新增的是着色器、材质、信号布网格和表现脚本，没有下载来源不明的素材或购买插件。

新增最多三份局部雾束、两盏无阴影瞬时冲击灯，脚步/干尘/碎光粒子上限分别96/80/128。布料每面104顶点、共四面，运行时克隆网格，不修改原资源。新增随机流独立于玩法，运动与粒子受Playing/暂停/升级状态约束；退出时清理运行时材质与网格。

URP表面与深度处理参考Unity官方的[材质工作流](https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/built-in/shader-built-in-configure-properties/standard-shader-metallic-vs-specular)和[粒子深度淡出实现](https://github.com/Unity-Technologies/Graphics/blob/master/Packages/com.unity.render-pipelines.universal/ShaderLibrary/Particles.hlsl)，实际编译使用本项目URP17.4。

按用户要求，只验证本轮模块编译、真实场景表现、运动、暂停、天气切换及清理；不重跑玩法回归或全面平衡/性能矩阵。证据保存在上级Reviews/AtmosphereR1-2026-10-13。画面取舍、舒适程度与最终品质由实际试玩反馈决定。
