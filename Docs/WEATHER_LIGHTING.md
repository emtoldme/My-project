# 声学花园 · 动态光影与天气

当前主场景 `Assets/Game/Scenes/Main.unity` 默认雨天。Play 后按 **F6** 依次切换雨天、雷雨、晴天；雨势缓慢过渡，雨停后地面继续缓慢干燥。Esc 暂停、升级面板和结算都会冻结天气时钟、雨滴、水花、风与扫描灯。

停止 Play 后，通过 **Reverb → 天气 → 选择天气控制器** 调整并保存场景。控制器位于 `Garden Weather · rain and light`。天气菜单只改预设，不重建场景。

| 参数 | 用途 |
|---|---|
| Weather | 开局晴天、雨天或雷雨 |
| Rain Amount / Wetness | 雨天的雨量与目标湿润度；雷雨使用满雨量 |
| Wind Strength | 雨线倾斜、阵风和麦穗摆动强度 |
| Particle Budget | 雨滴、水花、薄雾数量，默认1，降低到0.5可减轻开销 |
| Cloud Shadow Scale / Cloud Speed | 云影大小和移动速度 |
| Lightning | 雷雨的双脉冲闪电，可关闭 |
| Animate Searchlights | 扫描灯转动，可关闭；灯仍照明并投射阴影 |

三盏暖白/冷蓝扫描灯采用真实 URP Spot Light 和软阴影；八盏低位灯提供道路附近的局部光。现有太阳、4096级联阴影、SSAO、ACES与轻量Bloom继续使用。阴雨会降低日光、改变天空和环境色，并用可平铺的方向光Cookie投射移动云影；闪电同时影响太阳、环境、天空和雨滴亮度。没有改变战斗规则、碰撞或伤害。

雨滴采用世界空间拉伸粒子，随玩家移动的发射区覆盖当前画面；软粒子通过相机深度淡出与物体的交界。独立地面水花采样实际Terrain高度。积水网格贴合地形，边缘不规则，法线涟漪由局内时钟驱动。URP PBR负责灯光高光与现有环境探针反射。地形保留原有纹理层、道路绘制和法线，仅在前向光照中加入湿润度；陶瓷、黄铜和石墨材质也随天气改变光滑度。风动植物增加局部灯光接收，并为点/聚光阴影使用正确的光源方向。

反射使用环境探针和实时灯光高光，不是SSR、平面镜反射或光追，积水不会准确反射每个动态角色。新增天气没有独立音轨，沿用声音R1。远处地形的标准URP BaseMap回退不参与湿润动画；当前近景使用湿润前向材质，支持现有三层Terrain。

天气只读取GameLoop的局内时间。随机数独立于战斗；粒子手动推进，不依赖粒子寿命判定玩法。运行时克隆湿润材质和天空，禁用或退出时恢复原引用，不把临时变化写回美术资产。表现开销采用固定粒子上限、共享材质与只三盏投影扫描灯；目前不声称已完成全面性能优化或画质验收，最终观感以实际试玩反馈为准。
