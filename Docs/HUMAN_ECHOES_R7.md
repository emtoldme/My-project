# 归乡者与红色幽灵 R7

2026-10-14。回应“机甲违和，改成人类；怪物改红色幽灵并增加动态；天气变化后道路大片阴影闪烁”。分支 `art/human-echoes-r7` 从已接受的R6继续，使用同一独立workspace和正式Main。

## 人物与敌人

主角改为有真实头部、手部和骨骼的人类：浅色布衣、卷袖、深色工作裤、工作靴、旧挎包、冷青围巾。米制身高1.75米，Main外观放大1.12倍以保持屏幕辨识度。用户根目录的原始Blender文件未覆盖；原机甲在Main停用保留。

人类基础来自用户已有的Blender Human Base Meshes v1.4.1派生文件，授权CC0，作者Simon Thommes / Blender Studio；本轮制作原创衣物、头发、配饰、骨骼及姿态，不带入BlenderKit服装。来源和可编辑副本见 `SourceArt/HumanEchoesR7/README.md`。

`HumanMotion`按真实移动距离推进步幅，分辨前后/侧向移动，驱动大腿、小腿、脚、手臂、躯干与头部；待机有呼吸/微动，真实Dodge事件短暂前倾。不是外部动作包或完整动作捕捉；不含逐脚IK，实际姿态仍可继续精修。

普通、精英、冲锋者、落波者和首领均使用红色兜帽幽灵，保留规则对应的体型差异，以朱红/深绯红作轻微区分。黑色面孔与克制红眼、破碎下摆和两侧布条组成轮廓；密实红色核心不依赖Bloom。漂浮、移动倾斜、兜帽与下摆摆动、约0.36秒显形、真实受击显色和约0.65秒死亡消散均读取规则时钟。布料核心写深度，避免封闭半透明模型背面覆盖正面产生横向条带；薄边缘仍半透明。

`CombatViews`在预热时缓存 `IEnemyVisualPose`，每帧只传只读值快照；复用按Serial清理显形、速度和消散状态。死亡残影由真实EnemyKilled事件触发，固定12个预热实例，没有按击杀增长的实例或额外真实灯。暂停、日志、升级与出发前不推进动画；碰撞、命中、奖励、危险预警和唯一AudioDirector仍由原系统管理。

## 道路阴影

处理三处能够造成大块阴影跳变/不稳定的表现逻辑：

- 天气不再缓慢摆动太阳方向，主光阴影的投影方向保持稳定。
- 不再因雨量阈值或闪电强度直接更换/撤掉整张云影；在固定256×256运行时纹理内连续混合晴天与云影浓度。云影缓慢移动，闪电只改变照明亮度，贴图身份保持不变。停用时释放纹理、材质并恢复原主光状态。
- 49块平面地面与下方接近共面的兜底平面继续接收麦田/道具/人物阴影，停止投射自身阴影，避免互相遮挡。麦子、场景和人类仍投影。

局部装饰点灯不投影；广播/农机等聚光灯使用明确的低档256像素阴影预算，保留主光4096像素软阴影。已修改Main和涉及的程序地标/兴趣点Prefab，未扩大整体阴影贴图。不是关闭整个游戏的阴影。

固定太阳方向不会消除所有由移动麦浪、相机级联边界、抗锯齿或不同显卡产生的细微闪动。本轮针对用户报告的大面积天气阴影跳变修正，并观察实际Main天气过渡；不把短场景验证等同所有设备画质验收。
