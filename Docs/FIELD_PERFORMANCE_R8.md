# 地面、场景光照、旧物效果与性能 R8

> 后续用户实玩反馈：本轮削减损伤了光照，阴影仍闪烁。下述记录是 R8 的历史实现和测量，不能作为视觉验收通过的结论。R9 恢复灯光、阴影质量和近景麦田，并修复投影切换与遮蔽采样；见 [光照回退修复](LIGHTING_REPAIR_R9.md)。R8 的耗时数据不适用于 R9。

2026-10-14。用户要求优化性能，并优先提升地面、场景光照和道具效果，随后选择“流畅优先，可以减少远景密度和部分特效”。分支 `perf/ground-light-props-r8` 从R7继续，仍使用独立workspace和正式Main。人类/红色幽灵、R6麦田接触、探索与存档基底保留。

## 减少实际渲染开销

旧麦田把每株顶点复制进49个地块网格，九个整块使用最高细节；移动时重新合并大网格。R8使用12个共享实体模型，源网格合计2764顶点，地块只持有植株矩阵和颜色数据，不再复制数百万顶点。每个24米地块分成九个8米剔除区域；保留画面边缘的投影余量，近处使用实体穗粒，中远处降低网格与材质成本，最远区域按固定哈希顺序减少约三分之一植株。没有恢复麦子贴片。

模型细节按玩家距离带迟滞切换；近处保留纤维法线、粗糙度、透光和接触弯曲，中景减少微观法线，远景减少纹理采样和复杂局部光计算。实例矩阵保留每株高度、位置与朝向；熟度按小区域平均，颜色与摆动保留空间变化。49块仍循环回收，实例数组和属性块随地块重用。`ResidentWheatVertices`现在表示共享源几何，`ResidentWheatInstances`表示植株数，`SubmittedWheatTriangles/Batches`是相机提交量，三者不能混为一个指标。

主光由4096像素/四级阴影调整为2048像素/两级，距离65→48米；保留动态软阴影。SSAO半分辨率、四采样，深度法线重建改为中档；不降低主画面渲染分辨率，RenderScale仍为1。几乎不发光的装置不再渲染局部灯雾，激活时仍有光束，体积积分16→8步。

附近装饰灯共享8盏预算，按距离和范围筛选、带少量迟滞；太阳、玩家补光、瞬时受击光与真实状态驱动的三盏广播灯不进入该预算。旧物自身的灯光强度仍读取原叙事状态，预算只控制是否值得渲染。灯列表定期补充并清理已回收对象，没有每帧全场查找。

天气云影浓度未改变时不再反复绘制同一纹理；固定贴图身份、连续移动与启停恢复继续保留。拾取物缓存Renderer数组并仅在种类变化时重设颜色，氛围组件缓存界面组件引用。

## 地面与光照

新的泥土底色降低原地面明显的根状重复纹样，泥土/田底/收割秸秆保留不同色调与比例。Shader加入按纹理亮度与覆盖量偏置的层间过渡、低频色差、程序道路车辙，以及按低洼/土质分布的湿泥与小水洼。干土保持高粗糙度，湿润并不把整片地面变成亮塑料。

近处地面法线强度0.45，干燥粗糙度0.86；原始混合遮罩与探索布局不变。新法线由底色亮度作近似导出，不是扫描的真实高度数据。纹理导入使用Mip、三线性和4倍各向异性过滤。

黄昏主光与环境色重新统一，减少泛金色与过量Bloom；普通雨天补充散射天光，逐渐进入雷雨时再平滑变暗。原实体灯具、广播冷光及R7稳定云影继续工作。

新生成纹理实际消费路径为 `Assets/Game/Art/VisualIdentity/FieldR8/SoilAlbedo_Source.png`，对应 `SoilNormal.png`；原始生成文件未修改，旧纹理保留。生成方式、原图路径、完整提示词见[地面素材来源](ArtSources/FIELD_SOIL_R8.md)。

## 道具效果

旧家、筒仓与吉他的可拾取旧物增加小尺度、开放的三段声纹，靠近渐显，领取后与实体旧物一起隐藏。它们读取已有遗物可见状态，不新增奖励、真实灯或持续粒子系统。普通补给外观复用相同细声纹；原拾取、栏位、叙事日志与升级流程不变。

## 验证与测量边界

本次只验证这些模块。25项正式Main检查通过，包括实际出发、共享模型与数量、剔除提交、原分辨率、灯预算、接触、移动、暂停、雨天云影、真实旧物领取及效果隐藏、负坐标两公里回收和活动Shader编译。新地面绑定与近景干湿显示另有10项短场景复验。证据位于上级 `Reviews/FieldPerformanceR8-2026-10-14/play-final.log`、`ground-final.log` 及对应实景图片。最早的测试脚本引用错误与SSAO组合下的缺图已修正，失败日志留存，不计为通过。

性能对照使用同一台RTX4070 Laptop / i9-13980HX、Direct3D11、固定种子14104与1920×1080渲染目标。每阶段先预热120帧，再记录360帧，分晴天静止、雨天静止及雨中移动三段。规则以固定步长推进；场景真实渲染后读取一个像素同步GPU，保证后台测试实际完成绘制。对照保留同样同步开销，排除采图附近样本。

这是**同步渲染吞吐对照，不是完整游戏FPS**，不含正常窗口呈现与HUD绘制。GPU专用计时返回0，表示不可用，不应报告成零耗时；运行时渲染计数器也未返回有效值，几何量以源码/实际提交量说明。最早没有持续绘制的后台帧率数据作废，`Baseline`、`BaselineDX12`不用于结论。有效基线为 `BaselineSync`；最终数据与汇总见同目录的对照记录。没有完整十分钟试玩、全量回归、全设备矩阵或高敌人数稳定帧率保证。

有效对照每阶段353个样本（另排除采图附近7帧），地形种子14104、规则种子20261012一致。升级输入保护仍读取墙钟，真实战斗过程与移动时刻可能有少量差异，不是逐像素锁定的相同录像。下表是本机单次短场景结果：

| 同步渲染场景 | R7中位耗时 | R8中位耗时 | R7 P95 | R8 P95 |
| --- | ---: | ---: | ---: | ---: |
| 晴天静止 | 10.16 ms | 6.39 ms | 11.87 ms | 7.31 ms |
| 雨天静止 | 10.27 ms | 7.26 ms | 11.43 ms | 10.51 ms |
| 雨中移动 | 9.99 ms | 6.55 ms | 18.13 ms | 10.15 ms |

三段中位耗时降低约29%–37%。`Profiler.GetTotalAllocatedMemoryLong`记录的分配内存中位值由约447 MiB降到139 MiB；它不是进程全部内存或显卡显存。截图已确认独立包实际显示共享实体麦田、新地面与雨天光照，未通过缺图来换取测量结果。原始CSV和汇总在[对照数据目录](Benchmarks/R8)。

Windows包构建成功，0错误、487条构建警告，与R7同数量，主要为已有Sentis Shader变体警告。最终Shader和天气实景也在独立包对照中运行；本次没有重跑全量规则测试。

Windows试玩目录为根目录 `Builds/FieldPerformanceR8/ReverbField.exe`，须保留同目录数据与运行库。WASD移动，Space闪避，J日志，Esc暂停，F6晴/雨/雷雨，F8观景。正常启动不运行基准；`-reverb-benchmark`只是显式诊断入口，并使用独立存档路径。
