# HC02：旧物组合与返灯循环

2026-10-14。接续HC01，用户要求进一步打磨细节、发展组合玩法和有趣的循环。本轮在独立`gameplay/homecoming-resonance-loops`实施；没有新增永久百分比升级或武器数量。实际趣味与节奏由试玩决定。

## 一轮行动

认出旧物 → 在已熟悉的旧地选择一种共鸣 → 出门交战并收集碎音 → 决定把碎音用于走位/牵引/收拢经验，还是带回旧地返灯 → 修补衣襟、留下新记忆、重新调弦出发。

原来的额外遗物行囊保留。装备三件旧物仍提供原基础能力，但**共鸣架一次只选一对旧物**，三种行为不能叠加。换调必须回到旧地6米内，不能在远处即时切换来拼出无代价的万能组合；选“回到独奏”恢复HC01吉他普通残响。所有共鸣共享8秒冷却，普通Space闪避继续使用原冷却。

| 调式 | 配对 | 实际行为 | 代价与需要考虑的事 |
| --- | --- | --- | --- |
| 回针 | 针线盒＋吉他 | 首次共鸣闪避在起点留针；下次消耗1碎音，将玩家与针的位置交换，并在返回处产生原吉他残响 | 针限24米/24秒；超过范围断线。需要留意旧位置的敌人；无碎音时不能回针，普通闪避仍可用 |
| 牵弦 | 手套＋吉他 | 共鸣闪避消耗1碎音，留下2.5秒旧声源，牵引6米内最多12个普通追击者；玩家从另一边绕开 | 不改变冲锋者、落波者、精英或首领的行为与预警。无碎音时只保留普通吉他残响 |
| 归巢 | 针线盒＋手套 | 共鸣闪避消耗1碎音，让8米内最多12份现存经验进入原磁吸路径 | 经验必须真正到手才入账；没有经验可收时也可能浪费一次行动。此调式不发吉他伤害，没有吉他也能用 |

牵弦可把普通追击者带向已有残留区域；回针可把退路留在门廊或空地，再去田间收集。原武器仍按实际位置/寿命处理伤害，不给“组合成立”直接增加伤害百分比。普通闪避继续只通知既有P17/W06入口一次；回针重新基准化移动采样，避免瞬移拉出免费残留长线或污染追踪速度。组合攻击不递归产生新的闪避事件。

## 碎音与返灯

- 每**实际拾取6点局内经验**得到1份田间碎音，上限3；已满后不暗存无限溢出。局内经验不被消费或复制，调试直接加XP不生成碎音。
- 真实受伤散落1份碎音并清掉未满的一份进度，经验和永久成长不损失。无敌或护盾挡下的攻击不散落。
- 老屋/筒仓/吉他需先领取旧物；通用农机/秋千/广播箱只需发现。靠近这些地点6米内，可按J进入“旧物共鸣”换调或返灯。
- **返灯**交回3碎音，回复15%最大生命并获得一次护衣。护衣最多一针，抵挡一次真实伤害后消耗，额外给0.4秒缓冲；同一时刻不堆叠多针。全局30秒规则时钟冷却，满血且已有护衣时拒绝浪费资源。
- 换调不刷新共鸣冷却，重系回针会解开旧针。卸下必需遗物后调式失效；死亡/终局/重开清除碎音、针、牵引与护衣。
- 日志暂停冻结针、牵引与返灯冷却。返灯确认可在日志暂停中完成，音画事件等恢复Playing后交给既有表现/音频入口，避免暂停时提前播放。

三份碎音可以换三次战术行动，也可以留作一次休整。路线决定哪些配对先出现；田边通用地点从只读景物变成可返回的调弦/补给节点。没有增加循环刷取的永久奖励，也不需要强制完成新增刷怪清单。
