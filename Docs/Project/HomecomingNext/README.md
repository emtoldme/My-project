## 要交付的体验

玩家沿田间路找到旧家，认出门框上的身高刻痕，收起母亲留下的针线盒，同时获得一个额外遗物栏；在老筒仓拿到父亲的工作手套与第二个栏位；在倒下的果树旁拾起旧吉他，装备后成功闪避会留下短促残响。三处都可查看完整叙事文本。一次失败仍能带回已经确认的记忆与局外经验，下一次出发前用有限的永久升级点修补装备、整理行囊；不靠刷无穷杀怪填满数值树。

这是第一批实现基线，文案、数值与奖励节奏交各包细化；不能删掉老房子、老筒仓、老吉他，也不能只交策划不交可运行模块。目标是风味与选择，实际是否有趣由试玩判断。

## 交付模板

每包交付 `分支 + 完整提交SHA + PR链接（若有）`、改动目录、已实现/未实现、创建实例与调用示例、必要验证记录、已知问题、请求Codex适配的共享文件。PR目标为`gameplay/homecoming-next-ready`，不推main、不强推、不盲合其他包。缺接口先列出精确签名与理由，不能自行复制或修改共享契约。

资源必须保留.meta/GUID；场景修改使用Unity API，不手写YAML。包内预制体可由负责者制作，正式Main绑定由Codex完成。不改包依赖、URP、天气、既有灯光或唯一AudioDirector。新声音先提供事件需求，不新建播放器。正式资源需注明来源，不把外部参考图直接当游戏资产。
