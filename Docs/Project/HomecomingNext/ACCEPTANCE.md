# HC01 阶段整合验收

按用户偏好：每包只验证本模块编译、接口接入与关键行为。这里只在A/B/C/D集成节点做一次完整链路短试玩，不要求各包全量回归或重复构建。

1. 真实Main沿程序田间路抵达旧家→查看故事→靠近取得针线盒与第3槽；筒仓→手套与第4槽；吉他→入袋/装备→实际成功闪避产生一次特殊效果，能力实测与描述一致。
2. 所有当前物品有可查看叙事；已领取文本在日志再读，中文无缺字，正文可滚动。目标回应真实行为且不强制阻塞现有首领流程。
3. 离开使地块回收，返回站点状态/奖励保持；同模板多站不刷槽；负坐标固定种子复现，世界种子与战斗RNG分离。保留无空气墙及可走位开阔地。
4. 普通升级、遗物、开局永久升级共同作用且重开不叠乘；换装不刷HP，特殊效果不会递归。死亡同tick优先、暂停/升级冻结、重开清空局内账本。
5. 真实失败/胜利一次结算局外经验；合法购买一次；退出应用重进档案仍在；重复RunId不多领；模拟写盘失败不消费点或清空待结算，恢复/未来版本保护可见。验证存档与真实用户档案隔离。
6. 日志/升级/暂停/失焦/终局/F8输入无相互抢占；出发前战斗未开始；局内不能购买永久加成立刻热改。
7. 阶段节点生成Windows试玩包和清晰操作说明，不以接口测试或假宿主预览代替Main；用户试玩决定风味、收益节奏和探索时长下一步。

第一次整合保留原10分钟战斗结局。若它明显压缩叙事探索，由用户试玩反馈后再调整时长/独立探索模式，不由各包自行删除终局。
