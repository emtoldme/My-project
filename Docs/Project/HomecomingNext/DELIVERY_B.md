# HC-B 交付

基线 `9516b914ca57be950aafdb30f82824b5a8237900`。分支 `gameplay/hc-b-relics`。

## 逐步解锁

针线盒、手套、旧吉他从对应地点就能拿。后面三件要先把遗物用出来，拿不到时 `TryGrant` 返回 false，而且不记这一次领取，地点可以以后再试。

| 遗物 | 什么时候开 |
| --- | --- |
| 针线盒、手套、旧吉他 | 一开始就能领 |
| 裂罩灯 | 弦响 1 次，或缝补用过，或带着遗物行动 90 秒 |
| 钟钥匙 | 灯芯旺过 1 次，或弦响 2 次 |
| 搪瓷杯 | 任意遗物动作成功 3 次 |

每件还有 3 阶，只靠自己的动作升，重开清掉。升阶不另加伤害权威。

| 遗物 | 1 阶 | 2 阶 | 3 阶 |
| --- | --- | --- | --- |
| 针线盒 | 致命伤留下 25% | 用过一次缝补 | 装备满 40 秒后，缝补留下 30% |
| 手套 | 2.5 米，6 颗，12 秒 | 3 次后 2.9 米，7 颗，11 秒 | 6 次后 3.2 米，8 颗，10 秒 |
| 旧吉他 | 0.50 倍，只有弦响 | 2 次后 0.60 倍，加一条 1.2 米撕裂 | 4 次后 0.65 倍，半径 3.4 米，再加 1.6px 色差 |
| 裂罩灯 | 走 4 秒，再 +4% | 2 次后走 3 秒，再 +5% | 4 次后灯芯带 0.6px 色差 |
| 钟钥匙 | 闪避冷却 -8% | 4 次成功闪避 | 8 次。3 阶吉他一起戴时，弦响冷却 5.5 秒 |
| 搪瓷杯 | 16 秒，6% | 2 口后 14 秒，7% | 4 口后 12 秒，8% |

移速最高 6%+5%=11%，仍低于 12% 的上限。生命、拾取、闪避缩短也不越过种子上限。

## 音效和特效

规则只交出 `RelicFxCue`。宿主用现有的 AudioDirector 和一条 LineRenderer 播，不新建播放器。暂停时不要推进这些tween。同一拍如果已经有色差，新的一次盖掉旧的，不要叠到看不清。

撕裂不是出血。它是世界上的一条窄带子，1.2 米，铜褐色，0.35 秒内变细消失，跟现在的回声线同一类。色差只给 3 阶吉他和 3 阶灯：吉他 0.18 秒、1080p 下 1.6 像素、红青从人身上散开；灯更弱，0.12 秒量级的暖色边，规格里是 0.6 像素。HUD 不加色差。

声音都是短的一层，跟 P17 的电噪声和 W06 的残响分开。

| 事件 | 听感 | 时长 |
| --- | --- | --- |
| `sfx.relic.sewing-tin` | 针尖一下，然后布被拉上 | 0.28 秒 |
| `sfx.relic.work-gloves` | 皮皱一下，带一点麦粒 | 0.22 秒 |
| `sfx.relic.old-guitar` | 木箱拨弦 | 0.45 秒 |
| `sfx.relic.old-guitar.tear` | 同一拨弦，加一声干的高音断裂 | 0.40 秒 |
| `sfx.relic.old-guitar.chroma` | 拨弦偏一点音，尾巴很短 | 0.50 秒 |
| `sfx.relic.lantern-glass` | 玻璃轻响，火苗鼓一下 | 0.30 秒 |
| `sfx.relic.clock-key` | 铁钥匙一记 | 0.12 秒 |
| `sfx.relic.rain-cup` | 搪瓷敲一下，再一小口 | 0.35 秒 |

弦响成功时不要再调用 `NotifyRunDodge`。吉他没响、但戴着钥匙的那次闪避，改调 `TryNotifyDodge`。`TryDequeueFx` 把这一拍的规格取走。

主场景还没接这些声音和画面。这里没有跑 Unity。
