## 接入与修订

`GameplayNextInstaller`在每局开始前创建三份新的规则模块；两个锚点绑定在Main的`TuningAnchor01/02`，默认坐标(-9,5)、(9,-5)。配置可从 **Reverb → 玩法 → 打开玩法配置** 选择。

`GameplayFeedbackView`与`TuningMarkerView`消费真实只读视图。地面预警使用独立透明材质，按地形高度投射，保持在植被下可见；冲锋胶囊轮廓已修正。预算为12个攻击指示器及独立8个出生提示，避免出生提示被攻击占满后隐藏。暂停/升级冻结显示与规则时钟。

复用陶瓷机甲，冲锋者、落波者和首领通过比例与颜色区分。正式的新敌人模型/动画仍可在后续替换。

本轮修正了首领出生请求失败后无法继续入场的问题：等待已有出生预警结束后有限重试，不并发创建多个首领。狂暴声环的下一轮冷却从本招结束计算，防止下一次落波被宿主互斥预算拒绝。Clear同时清掉首领曾存在状态。
