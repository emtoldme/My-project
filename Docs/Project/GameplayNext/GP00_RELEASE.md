## 本次已交付

`Waffle.GameplayNext`提供三个规则模块、场景模块工厂、只读玩法视图与真实终局结果。共享宿主负责敌人生成和移动、三种几何危险的预警与连续命中、伤害、死亡清理、目标奖励与首领结算。模块只提交有界请求，不能直接扣血或发放收益。

每局有独立RunId与模块种子。生成、攻击、奖励请求去重且受预算限制；暂停/升级冻结模块，结束和重新开局清理状态。首领HP来自真实敌人，BossClear按真实死亡结算，同帧玩家死亡优先。目标只支持本轮D02治疗和D03吸附，每局至多两个不同目标各领取一次。

具体签名、请求接受语义与限制见[实际API](GP00_API.md)。任务所有权见[共用契约](CONTRACTS.md)，各任务卡仍是后续内容交付要求。
