# GP-A：敌人行为与遭遇节奏

给AI-A的任务卡。GP00 v1接口已固化，从GP00_RELEASE.md指定共同基线开始开发。请先读本轮README、CONTRACTS.md和工程AGENTS.md。你负责纯规则模块，不改共享战斗核心或主场景；适配需求交Codex。

建议分支`gameplay/gp-a-encounters`，独立目录。所有权：新增`Assets/Waffle/Scripts/Rules/Encounters/`及自己的必要测试/说明；测试复用现有程序集，不修改其他任务的文件。

## 目标

让玩家面对追击、冲锋和远程落波时做出不同走位，而不是仅增加敌人血量和速度。保留现有追击敌人。

## 内容

1. **冲锋者。** 接近后停步预警约0.8秒，锁定当时的方向，冲锋约0.35秒，再恢复约1.2秒。预警后不追着玩家拐弯；高速移动由宿主扫掠检测，越界停止。初值需保证普通步行能横移躲开，闪避是额外选择。
2. **远程落波者。** 尝试保持约6–9米距离，每约4秒在玩家当时位置锁定一处圆形落波；预警约1秒，生效约0.2秒，初始半径约1.1米。首轮不做实体飞行子弹、弹道反弹或复杂寻路。
3. **五段遭遇参数。** 按0/120/240/360/480秒提供普通敌人混编，逐步引入两种新敌人。使用现有并发/事件预算，不直接倍增上限。普通阶段保留4:00、8:00精英；首领阶段的停刷/降压由宿主统一覆盖。
4. **独立随机。** 以共同种子派生自己的确定性随机源，不消耗升级抽卡或既有奖励随机序列。

以上数值是首轮初值，提供可调数据，不写死在Update、模型或动画里。

## 交付切片

- A1：冲锋者规则与必要检查，附宿主适配请求；Codex接入试玩后再继续。
- A2：远程落波者与五段普通遭遇数据，附两种行为混编的复现说明。

## 必须通过

- 预警期间不伤害；锁定后不偷偷追踪；一次招式只提交一次伤害候选。
- 追击/冲锋/远程各有清晰行为，不需要指定武器或进化才能处理。
- 所有者死亡、回池世代变化、远离挪位后，不残留原位置攻击。
- 暂停/升级完全冻结，重开无旧计时器；池满或攻击预算满不补发爆量。
- 同种子与输入得到相同招式/生成结果；新模块关闭时旧追击路径保持可用。
