# GP-B：可选地图目标

给AI-B的任务卡。状态：待GP00共同提交后开工。请先读本轮README、CONTRACTS.md和工程AGENTS.md。你负责纯规则目标状态机，奖励由Codex在宿主兑现。

建议分支`gameplay/gp-b-objectives`，独立目录。所有权：新增`Assets/Waffle/Scripts/Rules/Objectives/`及自己的必要测试/说明；不修改场景、HUD、共享规则或其他任务目录。

## 目标

利用现有声学设施，给玩家“绕过去冒险取收益，或继续安全走位”的选择。忽略目标仍能正常完成本局。

## 内容

1. 两次可选调谐：约2:30和6:30各出现一个目标，最多同时一个。目标位置由宿主提供已校验的场景锚点，规则模块不查找Transform。
2. 玩家进入约2米范围自动调谐；累计约4秒完成，离开暂停进度，返回继续。60秒内未完成则过期；不扣血、不扣级、不强制拉回。
3. 第一次完成请求既有D02收益：回复20%最大HP；第二次完成请求既有D03收益：将现存经验送入磁吸路径。沿用实际规则入口，不凭空追加经验、不新增装备槽、不扣重抽次数。
4. 输出可读目标视图：位置、范围、状态、完成比例、剩余时间、收益文案。只允许宿主提供实际位置/阶段并接受收益请求。
5. 唯一领取键为runId+ObjectiveId。把“达成”和“宿主确认兑现”分开处理，宿主回调确认后封账，防重复调用或重开串奖。

收益采用宿主直接提交既有收益逻辑，首轮不要求额外生成拾取物，避免拾取池满导致任务奖励丢失。实际D02/D03调用位置由GP00/Codex冻结。

## 交付切片

- B1：单次调谐从出现到完成/过期的纯规则闭环，包含奖励确认。
- B2：两次独立时间点、完整只读视图、接线说明。位置选取与可见性由Codex/D在真实场景完成。

## 必须通过

- 离开/返回的进度符合上述口径；边界包含玩家中心，半径单位固定为米。
- 暂停/升级不推进调谐或过期时间；终局后不能领取；重开全部清空。
- 重复完成通知、宿主重复确认、旧runId请求均不多发奖励。
- 同tick死亡不兑现奖励；是否死亡与收益顺序以宿主裁决为准。
- 忽略、错过或放弃两个目标都不阻塞普通升级、首领生成或胜利。
- D03只磁吸已有经验，总量守恒；D02不增加最大HP，不会把生命回复到上限之外。

## 边界与提交

不要创建通用任务系统、任务树、存档、NPC对话、背包、局外货币、剧情或第二份奖励账本。不要用触发器脚本直接改HP/XP。

提交分支/PR或SHA、改动文件、状态转换说明、必要检查结果、收益适配请求与已知问题。场景绑定和实际可读性尚未完成时如实标注。
