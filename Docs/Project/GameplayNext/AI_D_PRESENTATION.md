# GP-D：危险可读性与玩法界面

给AI-D的任务卡。状态：待GP00共同提交后开工；可先做通用表现，实际联调依赖A/B/C。请先读本轮README、CONTRACTS.md和工程AGENTS.md。

建议分支`gameplay/gp-d-feedback`，独立目录。所有权：新增`Assets/Game/Presentation/GameplayNext/`及自己的说明；沿用现有表现程序集，不私自增加包或程序集依赖。对现有RC01GrowthHud/CombatViews的修改交适配清单，由Codex统一完成。

## 目标

玩家能从画面判断“哪里危险、多久后生效、地图目标值得不值得过去、首领剩多少血、为何本局结束”。所有显示来自真实只读快照。

## 内容

1. 共享Circle/Capsule/Annulus危险预警。预警、激活、结束三个状态明显区分；范围与时间直接读取宿主数据。用边界、填充/脉冲和方向表达，不能只靠颜色。
2. 冲锋方向标记、落波圆、扩散声环。地面标记避免被麦田完全遮住；可以使用克制的独立可读性层，但不得盖住玩家与成长卡。
3. 当前调谐目标的位置标记、离屏方向指示、实际进度、剩余时间和收益说明；完成或过期后正确消失。
4. 首领出生预警、实际HP条和阶段提示；首领尚未生成或已经死亡时不能显示假HP。
5. 结算补充真实胜负原因、存活时间、击杀、现有构筑、已完成目标数及首领结果。首轮不显示未经统计的DPS、伤害占比或评分。
6. 暂停/升级冻结危险动画；天气、F6、F11、现有三选一、重抽/放逐/跳过和R1声音保持可用。音频需求列清单给Codex，不新增AudioDirector。

初期复用现有材质、几何和IMGUI结构。无需这一轮迁移整套Canvas、制作新美术主题或实现旧UI技术提案中的全部目标。

## 交付切片

- D1：三种形状的有界预警表现和目标/首领面板布局，提供预览方法。
- D2：接入真实RunGameplayView和事件后的联调修订，实际结算与资源清理。

预览数据只能放隔离的编辑器预览，不接入正式Main；正式运行数据来自宿主，不能用计时器假装目标推进或伤害生效。

## 必须通过

- 世界空间范围与规则一致，雨天/雷雨、亮地面/暗地面、麦丛和技能效果中均能辨识。
- 同时12个危险标记仍遵守固定预算，重复事件不无限创建；对象复用时清旧形状和状态。
- 暂停/升级不继续倒数或淡出；终局/重开无残留预警、目标标记、首领条。
- 实际HP/进度/终局原因正确，未接线时显示等待或隐藏，不能展示伪造的玩法结果。
- 在1280×720和1600×900检查布局；三选一卡片和关键操作仍能正常点击。

## 边界与提交

不要扣血、发奖、生成敌人、改胜负或从粒子碰撞推导玩法。不要改天气/渲染/正式素材或直接编辑Main.unity。

提交分支/PR或SHA、改动文件、真实数据接线说明、布局截图、必要运行检查与已知遮挡问题。清楚区分预览截图和实际战斗截图。
