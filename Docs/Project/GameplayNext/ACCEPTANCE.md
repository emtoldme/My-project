## 三种短局试玩

1. **忽略地图目标。** 可正常成长并进入首领；不会因没做支线而卡死；早期有效构筑存在击败首领的可行路线。
2. **主动做两个目标。** 需要改变走位，但可中途放弃再返回；收益能感知，既不无关紧要，也不使后半局完全失去压力。
3. **另一条构筑。** 采用与第一局不同的已有武器组合，检查新敌人和首领没有强制某一种武器/进化；记录差异，不扩大成全武器矩阵。

至少一局雨天、一局雷雨检查预警；晴天做一次对照。覆盖1280×720与1600×900可读性。先复用现有调试命令跳到关键阶段做短测，再至少从正常开局完成一局，跳时验证不能代替完整局。
