## 一、四张地图美术风格草稿与同机位视觉参数 (Four-Map Visual Landscapes)

依据《麦田里的混响》核心世界观（**乡村怪谈 / 旧式机械 / 迷幻音波**）与主流幸存者（Survivors-like）战斗可读性法则，四张关卡地图确立了**从“开阔金秋”逐步坠入“冷寂工业与电磁虚无”**的渐变美术谱系：

```text
四图视觉世界观演进谱系 (Visual Evolution Continuum):
[秋收之路: 金黄麦浪、干土碎石与暖阳] 
    --> [旧农贸市场: 灰绿铁皮、锈蚀红褐与油污积水] 
        --> [第四粮仓: 深褐水泥筒仓、阴冷背光与琥珀钨丝微光] 
            --> [无线电荒原: 冷灰荒漠、绝缘电塔与高对比电弧蓝白]
```

### 1. 地图一：秋收之路 (Harvest Road) 
- **场景意境**：金秋麦浪起伏的乡野主道与收割边缘。平静表象下的怪谈异动，广袤开阔但危机四伏。
- **色彩倾向 (Color Palette)**：主调为干土深灰褐（`#382E25`）与熟成麦穗金黄（`#C89B3C`），点缀路边微绿杂草。
- **材质粗糙度与反射 (PBR Metrics)**：
  - 地表采用哑光漫反射，平均 Smoothness 控制在 `0.10 ~ 0.16`；
  - 零金属度（Metallic = 0.0），彻底消除反光塑料感，衬托地面预警圈。
- **光照方案 (Lighting Setup)**：
  - 单一暖色平行主光（Directional Light，RGB `[1.0, 0.94, 0.82]`，强度 1.15）；
  - 斜俯视 55° Pitch / 45° Yaw，投射出清晰的 45° 麦秆修长斜投影。
- **物件疏密与同机位参数**：
  - 中心半径 6m 保持为踩踏路面与极矮麦茬（高 0.25m~0.5m），外围环带为 2.0m 高麦丛错落集群；
  - 战斗核心区视野阻挡率为 0%，麦浪边缘起伏连绵。

### 2. 地图二：旧农贸市场 (Old Market)
- **场景意境**：废弃多年的乡村农贸集市。铁皮雨棚、生锈摊位铁架与碎瓦泥坑构成的破碎街巷。
- **色彩倾向 (Color Palette)**：灰绿剥落油漆（`#4E5E4E`）与氧化铁锈红褐（`#4A2E20`）互锁，地面带有暗黑油污反光。
- **材质粗糙度与反射 (PBR Metrics)**：
  - 铁皮与摊架具有局部金属度（Metallic `0.30 ~ 0.65`）；
  - 局部摊位顶棚粗糙度拉开（Smoothness `0.45 ~ 0.60`），呈现湿润与锈蚀交织的冷硬质感。
- **光照方案 (Lighting Setup)**：
  - 略带阴霾的冷白散射主光（RGB `[0.85, 0.88, 0.90]`，强度 0.95）；
  - 窄巷阴影交叠较深，需靠摊位边缘的反光与地面微弱受光区分道路走向。
- **物件疏密与同机位参数**：
  - 十字路口与多出口通道宽度保持在 3.5m ~ 5.0m；
  - 摊位与杂物箱作为绝对阻挡体（TEST_ONLY 静态代理体），中心战斗节点始终留有 2 处以上退路。

### 3. 地图三：第四粮仓 (Fourth Granary)
- **场景意境**：高耸混凝土筒仓群下的密闭装卸站。深沉压抑的巨大箱体共鸣空间，工业秩序与回声压迫。
- **色彩倾向 (Color Palette)**：深灰黑水泥（`#23211F`）基底，搭配电木暗黑与暗橙红（`#E06020`）真空管弱受光。
- **材质粗糙度与反射 (PBR Metrics)**：
  - 粗糙混凝土表面 Smoothness `0.08 ~ 0.14`，强力吸光；
  - 柱网基座与排气阀金属管道带有低光泽（Smoothness `0.25 ~ 0.35`，Metallic `0.50`）。
- **光照方案 (Lighting Setup)**：
  - 低角度阴暗顶光，局部点缀橙黄色工业警示泛光（模拟 Old Sonic Modulator 电子管橙光波长）；
  - 整体对比度偏高，依靠柱网阴影创造强烈的立体透视分割。
- **物件疏密与同机位参数**：
  - 粗大立柱（直径 1.8m）按 12m 网格矩阵排列，遮挡局部直射弹道，形成绕柱迂回与近身防守节奏。

### 4. 地图四：无线电荒原 (Radio Wasteland)
- **场景意境**：地平线尽头的广袤枯寂盐碱荒原。锈蚀高压电塔耸立，无处不在的电磁微波与空旷虚无。
- **色彩倾向 (Color Palette)**：冷灰白碱土地表（`#5E6164`）与干枯风化残渣，强对比电弧冷青（`#50D2D2`）与纯白火花。
- **材质粗糙度与反射 (PBR Metrics)**：
  - 干燥细盐碱土极度粗糙平缓（Smoothness `0.05 ~ 0.12`）；
  - 偶见的绝缘瓷瓶与风化镀锌铁塔构件呈现高光点状散射。
- **光照方案 (Lighting Setup)**：
  - 苍白无遮蔽的高照烈日（RGB `[0.92, 0.94, 1.0]`，强度 1.25）；
  - 阴影锐利且短，视野极度辽阔，完全由电弧特效与长距离投射物划破宁静。
- **物件疏密与同机位参数**：
  - 宽达 60m 以上的几乎无障碍腹地，仅有偶发生成的“信号安全岛”以地表同心圆微弱发光界定区域。

## 三、实机视觉缺陷解决与给 2 号装配的 5 项最高优先级建议

结合此前 `REVIEW.md` 与实际相机截图（`world.png` / `Combined-world.png`）中暴露出的**“麦丛单株偏细稀疏”、“地表拼接机械重复”、“全图单一黄褐色缺乏深度”**等核心画质问题，主美为 2 号（场景装配）制定了必须严格执行的 **5 项装配调优规范**：

1. **【优先级 P0】强制麦田实行“三级嵌套簇群”（告别单株稀疏感）**：
   - 严禁单独散落单棵 `P_Wheat_A` 或 `P_Wheat_B`；
   - 必须以“1 株高麦（LOD0，强制锁定）+ 1~2 株麦茬残桩（`P_CutStubble`，护住底部透空区）+ 1 丛低矮贴地草（`P_WildGrass`）”为一个逻辑复合簇；
   - 每个簇整体应用微随机 Yaw 旋转（0~360°）与整体 Scale（`0.9 ~ 1.15`），使麦田根部饱满、顶端错落，彻底解决麦秆单薄发飘的塑料感。
2. **【优先级 P1】场景中心 7m 绝对清空与预警高可见度契约**：
   - 场景中心半径 7m 的主力战斗圈内，**严禁布置任何 2m 高麦丛**；
   - 中心仅允许地表微细踩踏纹理与极微量贴地残桩（高度 ≤ 0.3m），确保玩家在此高速闪避、索敌，且敌人投射物与地面朱红预警圈（`#FF3B30`）具备 **100% 毫无遮蔽的高对比度视认性**。
3. **【优先级 P2】地表混合破除大方块硬接缝（采用平滑过渡与小路穿插）**：
   - 24m 样板内，必须由干土地面（DrySoil）作为主基底，以踩踏小路（TrampledPath）呈有机折线或环形穿插其间，边缘铺设密集麦草残茬（DenseStraw）；
   - 地表材质过渡严禁用直线硬切，必须使用平滑渐变（SmoothStep）或小碎面穿插，打碎大面积平铺瓷砖感（Tiling Fatigue）。
4. **【优先级 P3】视觉深度色彩分离（冷暖对抗调色法）**：
   - 为避免“从上到下一片黄褐色”，地表背阴面与外围无麦区应使用微冷调干土（`M_RF01_GroundContinuation`），而高麦穗在侧光照射下呈现高饱和金黄（`#FFC845`）；
   - 回声紫红（`#B863A0`）与传播金黄（`#FFD700`）在深沉冷灰暗褐背景的映衬下，视觉穿透力大幅提升。
5. **【优先级 P4】环境装配纯粹性（只出 Prefab，杜绝逻辑/时间污染）**：
   - 产出的场景与环境 Prefab（如 `P_RC01_HarvestRoad_Environment.prefab`）**严禁包含任何 Camera、Directional Light、GameLoop 脚本、CombatModule 或额外音频组件**；
