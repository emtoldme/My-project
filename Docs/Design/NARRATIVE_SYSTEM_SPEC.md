## 一、 设计哲学：中西部磁带现实主义（Midwest Tape-Realism）

我们拒绝两种常见的叙事陷阱：
1. **纯怪异与谜语人**：为了诡异而诡异，最后不知所云；
2. **好莱坞式个人英雄主义**：主角端着机枪高呼打倒邪恶科学家。

《麦田里的混响》的核心是**归乡、记忆的重构、哀悼的完成，以及在铁锈与噪音中夺回历史命名权**。
叙事遵循**三套语调（The Three Frequencies）**与**四大视听载体**：
- **泥土与铁锈（The Rust - 玛拉/父亲）：** 疲惫、生活化、带着柴油与零件的物理重量。
- **合成器与安宁（The Clean Signal - 沃尔特）：** 伪官方、冰冷温和、将擦除痛苦与擦除人性等同起来的危险诱惑。
- **历史的杂音（The Static Tape - 红色麦收/露西）：** 充满撞击、抗争与未竟真相的低保真磁带存根。

## 四、 核心历史物证存根定义

### 磁带编号：`TAPE_1968_OCT14`
- **标题：** 《第四粮仓夜班调度记录（残片）》
- **时间与地点：** 1968.10.14 23:42 · 第四粮仓主控机房
- **录音转录：**
  > *“沃尔特，谷尘浓度传感器已经过载了！快拉闸放风！……等等，你为什么要反锁总控阀门？沃尔特！外面的工友还在脱粒线上！把门打开！——[激烈撞门声与剧烈电流爆音]”*
- **阿瑟的调查备忘：**
  > *这盒磁带被父亲焊死在收割机继电器内侧。沃尔特当年不仅在场，而且是他亲自切断了安全通道。所谓‘麦收骚乱’根本不是意外，而是一场由管理层冷血关闸引发的惨剧。*

## 五、 代码工程落地清单

本模块已包含可编译、可测试的独立源码：
1. **`Reverb.Narrative.asmdef`**：独立叙事程序集，避免与表现层或测试框架产生循环引用。
2. **`NarrativeModels.cs`**：定义对白原子、触发器表达式、物证存根数据模型。
3. **`NarrativeDatabase.cs`**：ScriptableObject 架构，支持未来可视化 Inspector 配置。
4. **`HarvestRoadNarrativeScript.cs`**：内置秋收之路完整剧情节点工厂。
5. **`NarrativeDirector.cs`**：非阻断式局内叙事总监，带优先级抢占和状态留存。
6. **`NarrativeRadioHud.cs`**：车载收音机 HUD，支持电传打字机效果、信号波段与杂音示警。
7. **`CassetteArchiveViewer.cs`**：历史物证与磁带调查档案回放查看器。
8. **`NarrativeDirectorTests.cs`**：包含时间戳判定与优先级抢占的双重单元测试。
