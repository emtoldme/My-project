# 《麦田里的混响》UI/HUD 实装规范 (Clean & Practical UI Spec)

**版本：** v2.0 Practical Master  
**设计目标：** 
1. **服务割草核心体验：** 俯视角 3D 动作割草，**信息清晰、绝不遮挡视野、0.5秒内完成判断**是绝对第一优先级。
2. **克制的世界观表达：** 用最轻量、易落地的视觉符号（收音机刻度、老式色调、轻微杂讯）传递 1988 年乡村怪谈质感，**坚决不做笨重遮挡面板，不做拖沓繁复的过渡动画**。
3. **高可落地性：** 基于 Unity 标准 UGUI / TextMeshPro / 9-Slice Sprite 制作，轻量高效，保证高帧率。

---

# 一、主战斗 HUD：通透、低遮挡、高可读

主战斗画面必须保持 90% 以上的可视面积无遮挡，让玩家专注于麦田环境与怪物动向。

```
+-----------------------------------------------------------------------------------------+
| [88.5 MHz]  [======================= 经验条 =======================]  [12:35] [击杀 842] |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|                                                                                         |
|                                   [ 俯视角主战斗区域 ]                                   |
|                                    (完全通透，无遮挡)                                   |
|                                                                                         |
|                                                                                         |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
| [ 4个武器槽位 ]       [ 生命值: [████████████░░░░] 75/100 ]            [ 6个配件槽位 ]    |
| [ 技能冷却CD ]        [ 护盾: [██████░░░░] 30/50          ]            [ 被动等级角标 ]   |
+-----------------------------------------------------------------------------------------+
```

## 1.1 顶部状态栏（通栏微缩）
* **收音机频率经验条（XP Bar）：**
  * 位于屏幕正顶端，高度仅 12px~16px，带 80% 透明度黑底。
  * 表现为收音机频段游标（`88.0` ~ `108.0 MHz`），内部填充为麦浪黄或示波青色。
  * 左侧紧凑字符显示当前等级与频段：`Lv.8 (94.2 MHz)`。
* **时钟与击杀（Timer & Counter）：**
  * 右上角等宽字体：`12:45`，下方小字显示消灭怪物数。到达整点难度跃升时仅文字单次呼吸闪烁，不弹大遮罩。

## 1.2 底部中央：生命值与护盾（视觉焦点）
* **胶囊血条（Health Bar）：**
  * 紧凑长条形（宽 320px，高 24px），放置在屏幕底端中央。
  * **主色：** 铁锈红（`#A63A2E`），残血（<30%）时边缘微微脉动呼吸。
  * **受击反馈（白条残影）：** 受到伤害时，被扣除的血量立即变为半透明白色/黄色停留 0.3 秒，随后平滑滑落，清晰感知扣血量。
  * **受击红晕：** 受大额伤害时仅在屏幕四角产生单帧快速暗红晕，不挡视野。
* **护盾条（Shield Bar）：**
  * 紧贴血条上方，高度仅 6px，呈亮青色导电微光。

## 1.3 底部两侧：装备与配件栏
* **左下角武器栏（4格）：**
  * 4 个 56x56 像素半透明方框，显示当前拥有的攻击装备。
  * 冷却状态使用最经典的半透明扇形/自下而上遮罩，一目了然。
  * 达成超武/满级时，边框变为细金边。
* **右下角配件栏（6格）：**
  * 6 个 44x44 像素紧凑方格，显示被动道具。
  * 右下角带有清晰小数字（`Lv.1` ~ `Lv.5`）。

# 二、三选一升级界面（Level-Up Tuning）：极速决策

幸存者单局要选卡 30 次以上，界面必须做到**无需犹豫、一眼抓准关键信息、支持键盘秒选**。

```
+-----------------------------------------------------------------------------------------+
|                                  [ 频段调谐 TUNING (LV.9) ]                              |
|                                                                                         |
|      +-------------------+      +-------------------+      +-------------------+        |
|      | [武器图标]        |      | [配件图标]        |      | [新武器图标]      |        |
|      | 广播音叉   Lv.3   |      | 绝缘地线   Lv.1   |      | 高压接地缆  NEW!  |        |
|      | ----------------- |      | ----------------- |      | ----------------- |        |
|      | 声波范围 +25%     |      | 拾取范围 +30%     |      | 在脚下拖曳高压线  |        |
|      | 击退力度提升      |      | 移动速度 +5%      |      | 周期性释放连锁电弧|        |
|      |                   |      |                   |      |                   |        |
|      | [ 快捷键: 1 ]     |      | [ 快捷键: 2 ]     |      | [ 快捷键: 3 ]     |        |
|      +-------------------+      +-------------------+      +-------------------+        |
|                                                                                         |
|                      [ 快捷键: R 刷新 (剩余 1 次) | 空格 确认 ]                         |
+-----------------------------------------------------------------------------------------+
```

### 关键规范：
1. **背景处理：** 游戏世界暂停，背景轻度压暗 50%，禁用重度模糊，减少性能开销。
2. **卡牌信息结构（自上而下）：**
   - **头部：** 清晰图标 + 装备名 + 当前等级变化（例如 `Lv.3 → Lv.4`；新装备打醒目黄底黑字 `NEW!` 标签）。
   - **中部：** 最多 2~3 行精简文字。**数值变动统一用亮黄色/亮绿色标出**（如 `+25% 伤害`）。
   - **底部：** 大字按键提示（`[1]`、`[2]`、`[3]`），方便键盘玩家直接盲按。
3. **交互节奏：** 弹窗 0.1 秒内就位，点击后 0 秒切回战斗，无拖沓的开卡/翻转过场。

# 三、精英宝箱界面：爽快即时反馈

* 击杀精英掉落的工具箱，触碰即开。
* 屏幕中央弹出浮动奖励卡片（获得 1/3/5 项装备升级或代币）。
* 伴随一声清脆利落的机械弹扣声。
* **支持空格键或点击任意处一键跳过**，秒速入包，维持割草节奏。

---

# 四、暂停手账（ESC / Tab）：清爽总览

暂停界面分为左右两列，兼顾查看构筑与剧情碎片：
* **左侧（构筑全览）：**
  - 列出当前 4 武器 + 6 配件的详细数值面板（实际伤害、冷却、射程、击杀贡献率）。
* **右侧（任务与系统）：**
  - 当前关卡目标与已收集的物证磁带。
  - 基础系统设置按钮（继续、音量、放弃并返回）。

# 五、游戏结束与结算界面（Game Over / Settlement）

* **阵亡/结算瞬间：** 
  - 画面快速褪色变暗（0.3 秒），屏幕中央横向闪过一条显像管关机白线。
* **结算发票（农场账单风格）：**
  - 一张发黄的简洁纸质账单，自上而下清晰罗列：
    - **存活时间**（例如 `14:22`）
    - **消灭怪物数**（例如 `1,420`）
    - **获取局外货币**（例如 `旧铜代币 x68`）
    - **解锁物证**
  - 底部清晰大按钮：`[ 重新出征 (空格) ]` / `[ 返回农舍 (ESC) ]`。

# 六、视觉色彩与文字规范 (Design Tokens)

| 要素 | 取色 (Hex) | 用途说明 |
| :--- | :--- | :--- |
| **背景底板** | `#1A1A1A (85%透明)` | 弹窗、血条底色，保证文字对比度，不遮背景 |
| **主文本** | `#E8E6DF` (米白) | 标题、装备名称、正文说明 |
| **高亮/经验** | `#E5A93B` (麦浪黄) | 经验游标、数值增强项（如 +20%）、新物品标签 |
| **调谐/青色** | `#38B2A3` (示波青) | 护盾、频率提示、特殊加成 |
| **生命/警报** | `#A63A2E` (铁锈红) | 玩家血条、受伤残血警报 |

* **字体选择：** 
  - 界面数字与等级：使用等宽/粗黑无衬线体（保证 1080p 下任何距离边缘锐利）。
  - 描述与说明：清晰的标准无衬线体，字号适中，行距 1.2 倍。
