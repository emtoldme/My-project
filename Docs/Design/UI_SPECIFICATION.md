# 一、视觉设计语言与设计系统 (Design System)

## 1.1 风格基调与材质隐喻 (Materials & Metaphors)
* **冷轧铁板与工业锤纹漆（Hammered Metal & Enamel）：** 面板背景采用1970-80年代工业仪器常见的灰绿/铁锈棕锤纹漆，边缘带有细微的露白摩擦划痕与暗红锈斑。
* **弧形亚克力与老式有机玻璃（Convex Acrylic & Scratched Glass）：** 仪表表盘具有凸面反光与微弱漫反射高光，在强光下可见细小的内部应力裂纹与指纹油污。
* **真空荧光管与发光二极管（VFD & Nixie Glow）：** 状态指示灯与数字并非纯矢量色块，带有老式VFD荧光屏特有的青绿色漫射晕光，或数码管特有的橙黄色辉光。
* **CRT 显像管与示波线（Cathode Ray Tube & Scanlines）：** 关键波形与雷达界面带有横向微细扫描线（Scanlines）、荧光粉余辉（Phosphor Persistence）以及轻微的球形桶状畸变（Barrel Distortion）。

## 1.2 调色板系统 (Color Palette)

| 语义角色 | 色值代码 (Hex) | 材质与光学表现 | 叙事象征 |

## 1.3 字体排印规范 (Typography)

* **主要数值与频率显示：** 老式机械字轮 / 七段数码管 (LED 7-Segment) / 荧光管等宽字体。
  * *用途：* 战斗时间、调频赫兹数（等级）、血量计、弹药/冷却倒计时。
* **标牌、按钮与模块标题：** 凸印胶带打字机字体 (Dymo Embossed Label) / 工业模板喷漆字 (Stencil Gothic)。
  * *用途：* 装备名称、机修属性标签、警告字样（如 `CAUTION: 500V`）。
* **叙事手账、说明书正文：** 机械打字机墨印字体 (Courier Typewriter 粗墨晕染) 或带有圆珠笔手写修正划线的斜体。
  * *用途：* 父亲的改装笔记、露西的调查备忘录、道具背景故事。

# 二、主战斗 HUD：战场仪表盘布局 (In-Combat HUD)

主战斗界面拒绝浮动在空中的现代极简色块，整体UI被封装为一个**固定在屏幕底栏和边角的老式便携调频收发机控制面板**。

```
+-----------------------------------------------------------------------------------------+
| [O] 98.4 MHz (LV.12)  [================== 调频进度槽 (XP) ==================]  (12:45)  |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|                                                                                         |
|                                   [ 俯视角主战斗场景 ]                                   |
|                                                                                         |
|                                                                                         |
| [装备槽位: 4个驻波发射器]                                            [配件槽位: 4个物理零件] |
| +----+ +----+ +----+ +----+                                          +----+ +----+ +----+ +----+ |
| | 01 | | 02 | | 03 | | 04 |                                          | A  | | B  | | C  | | D  | |
| +----+ +----+ +----+ +----+                                          +----+ +----+ +----+ +----+ |
|                                                                                         |
+-----------------------------------------------------------------------------------------+
| [ 镀锌水银管: 核心信噪比 (HP) ]            [ 指针表头: 瞬时信噪比 ]    [ 步话机通信指示灯 ]      |
| [████████████████████░░░░░░░░] 74/100      (  / VU Meter \ )         [● 玛拉正在收听...]       |
+-----------------------------------------------------------------------------------------+
```

### 2.1 顶部：经验槽与时钟（【频率标尺与广播时间表】）
* **机制对应：** 经验值条（XP Bar）、玩家等级（Level）、存活时间（Survival Timer）。
* **UI表现：**
  * **经验槽（Tuning Dial）：** 横跨屏幕顶部的长条形收音机刻度尺。滑动游标随着碎磁的收集从左往右滑动（例如从 `88.0 MHz` 滑动至 `108.0 MHz`）。指针所过之处带有橙黄色钨丝背光。
  * **等级显示（Channel Display）：** 刻度尺左侧为一个凸凹不平的转轮指示窗，显示当前谐振频道：`CH. 07`（对应Lv.7）。
  * **时间显示（Transmission Timer）：** 右侧为一个带有机械翻页音效的翻页钟或老式石英荧光表，格式为 `14:28`。每当整点阶段（如 `05:00` / `10:00`）切换时，钟表边缘会有红字警报标签闪烁。

### 2.2 底部左侧：生命值与护甲（【镀锌水银真空计与消磁保护层】）
* **机制对应：** 当前生命值（HP）、最大生命值、护盾值（Shield）。
* **UI表现：**
  * **血条（The S-Meter Tube）：** 一根横置的粗壮真空玻璃管，内部充盈着带有微弱气泡浮动的浓稠红色水银发光柱。
    * 受到伤害时：玻璃管内的水银柱剧烈颤抖震荡，伴随玻璃被金属敲击的清脆“当啷”震音，血条扣除部分留下半秒钟的暗红残影。
    * 濒死状态（HP < 25%）：真空管两端迸发出幽蓝色危险电弧，屏幕边缘出现模拟信号严重失真的行抖动（CRT Horizontal Glitch）与低频脉冲呼吸红晕。
  * **护甲/护盾（Grounding Shield）：** 环绕在水银管外部的黄铜接地编织网。有护盾时，金属网呈现亮青色导电微光；护盾破碎时，伴随保险丝熔断的“啪”声和一缕灰烟粒子，黄铜网变暗变锈。

### 2.3 底部中央：输出强度计（【机械式 VU 动圈表头】）
* **机制对应：** 当前角色的输出功率、连击计数与过载爆发指示。
* **UI表现：**
  * 一块双指针扇形动圈伏特/分贝表。
  * 左指针对应“发射功率（DPS/击杀速率）”，右指针对应“空间噪音压强（周围怪物密集度）”。
  * 玩家攻击命中怪物成片倒下时，黑色的细长指针随着重低音打击感剧烈向上弹跳（`0 dB` 甚至冲入 `+3dB` 红区）；
  * 当双指针同时压入红色极限区时，表盘顶部的一盏琥珀色过载氖灯点亮，伴随高频啸叫，提示当前构筑处于爆发峰值。

### 2.4 两侧：装备与配件栏（【接线端子与模块卡盒】）
* **左下角【4个主动武器槽位】：**
  * 表现为带有金属锁扣的矩形黑色电木插槽。
  * 内部插入带有手柄的线圈模块、音叉模块等。每个槽位底部配有一枚微小的冷光指示灯，跟随武器的内置冷却时间（Cooldown）以呼吸速率充能闪烁，冷却就绪触发攻击时瞬间爆闪。
* **右下角【4个被动配件槽位】：**
  * 表现为拧在铜排上的外置电容、继电器、铜徽章。图标采用发黄工程图纸风格的单色微缩线稿。
* **超武进化（Harmonic Lock）标识：**
  * 当某武器与配件完成协同超武进化后，两个对应的槽位之间会弹射出一条带绝缘编织层的粗铜线，两者指示灯锁定为高亮品红色恒亮，图标外框浮现铆钉电弧。

# 三、核心弹窗交互：升级与三选一调谐 (Level-Up Tuning)

升级画面不仅是暂停选卡，而是**“主角停步旋转收音机旋钮，在无尽噪音中捕获一段隐藏波形”**的仪式。

```
+-----------------------------------------------------------------------------------------+
|                     [  SIGNAL LOCKED: 94.7 MHz  |  信 号 锁 定  ]                        |
|                     <<< 请拨动旋钮选择要调谐的现实增益回路 >>>                          |
+-----------------------------------------------------------------------------------------+
|                                                                                         |
|   +--------------------+     +--------------------+     +--------------------+          |
|   | [ 01 / 音叉震荡 ]   |     | [ 02 / 步话改装 ]   |     | [ 03 / 工会徽章 ]   |          |
|   |  - 武器强化 -      |     |  - 新武器接入 -    |     |  - 被动回路 -      |          |
|   |                    |     |                    |     |                    |          |
|   | [ 粗糙黑白图示:    |     | [ 粗糙蓝图图示:    |     | [ 粗糙手绘图示:    |          |
|   |   加长音叉共振齿 ] |     |   高压接地铜缆 ]   |     |   1968红铜星徽 ]   |          |
|   |                    |     |                    |     |                    |          |
|   | "增加30%声波穿透， |     | "在脚下拖曳高压线，|     | "拾取范围+25%，    |          |

|   |                    |     |                    |     |  释放反向消磁脉冲" |          |

```

### 3.1 弹出转场特效 (Tuning Transition)
1. **时间冻结与视觉退行：** 游戏世界暂停，3D场景迅速脱色并蒙上一层深蓝色的雪花噪点，世界背景音（环境风声、怪叫）变为极其低沉缓慢的黑胶底噪与高频啸叫。
2. **调谐窗展开：** 屏幕中央像是老式示波器开机一样，自中心水平展开一条耀眼的绿色亮线，随后上下拉开，形成三块带有金属边框与压敏标签的卡牌。
3. **音效配合：** 巨大的重低音“砰——”，伴随调谐旋钮弹力咬合的“喀哒、喀哒”齿轮进位音。

### 3.2 卡牌视觉构成 (Card Visual Anatomy)
* **卡牌顶栏：** 压印有发黄的塑料标签胶带（Dymo Tape），字体为白字黑底凹凸感，标注来源与类别（如 `MOD-A: COIL` / `MEMO: MARA`）。
* **中央插图视效：**
  * 拒绝彩色卡通立绘！采用**1980年代复印机印在再生纸上的高对比度单色网点图（Halftone Dot Print）**，或是圆珠笔画在发黄网格纸上的草图。
  * 鼠标悬停（Hover）在卡牌上时，插图会发生微妙的静电毛刺闪烁（Phosphor Flickering），耳边响起轻微的调台人声碎片（如露西念读档案的模糊半句）。
* **升级星级（Pips）：** 卡牌底部不是现代的金星，而是**4-5枚小圆孔真空指示灯**。已升级的孔位亮起微弱的橙黄钨丝，未升级的孔位为暗空洞，本次升级的孔位呈高亮跳动。

### 3.3 交互反馈 (Haptic & Audio Feedback)
* **鼠标/手柄选中切换：** 每切换一张卡牌，示波器界面中央的波形曲线实时变换（从方波变成锯齿波、尖峰波），伴随老式继电器吸合的“哒”声。
* **确认选择：** 点击确认后，被选中的卡牌如被高压电弧击穿一般爆发出强烈的冷青色光晕，其余两张卡牌迅速失焦被噪点吞没坍缩，随后画面伴随显像管去磁的“啵鸣”瞬间恢复正常战斗。

  4. 随后弹出改装部件与历史文本说明，强化战斗收益与剧情解密并行的快感。

# 六、终局倒计时与清算视效 (The Sunday Purge & Game Over)

幸存者游戏中玩家阵亡或坚持到极限关门时刻的视效至关重要。本作将“死亡”与“结算”彻底从系统UI转化为**世界观内的现实回弹**。

### 6.1 濒死与抹除（Defeat / Erasure）
* 当生命值降为零时，没有传统的“YOU DIED”血字。
* **画面表现：**

# 八、Unity URP / UI Toolkit 落地技术规范 (Technical Implementation)

为了保证上述UI在 60-144 FPS 下稳定运行，且在各种分辨率下保持边缘锐利与模拟质感，制定以下工程实施方案：

## 8.1 架构分层建议
```
UI Canvas (Overlay / Screen Space Camera)
├── Layer 0: World Space Dashboard (可选：车内/背包物理UI模型)
├── Layer 1: Rustpunk HUD Base (9-Slice 铁锈框架、仪表底板)
├── Layer 2: Dynamic Gauges & Tubes (水银管Shader、VU表头指针插值)
├── Layer 3: CRT & Signal Glitch Post-Processing (专用全屏/局部UI材质)
└── Layer 4: Interactive Labels & Tooltips (Text & Modals)
```

## 8.2 核心 Shader 需求规范 (Shader Graph / HLSL)

### 1. `UI_MercuryTube.shader` (水银真空管材质)
* **输入属性：** `_FillAmount (0~1)`, `_JitterIntensity`, `_GlowColor`, `_BubbleSpeed`.
* **实现逻辑：** 
  * 利用SDF（带符号距离场）绘制圆角胶囊体液柱；
  * 根据当前角色受击事件传入 `_Jitter`，液柱边缘产生基于正弦波叠加的高频表面张力晃动；
  * 液柱顶部带有弯月面反光与细小气泡平移UV。

### 2. `UI_CRTSignalGlitch.shader` (模拟信号与示波器材质)
* **输入属性：** `_ScanlineDensity`, `_Curvature`, `_PhosphorDecay`, `_NoiseStrength`.
* **实现逻辑：**
  * 顶点着色器应用轻微的鱼眼畸变算法：`uv = uv * 2.0 - 1.0; uv += uv * dot(uv, uv) * _Curvature;`；
  * 片元着色器叠加水平扫描线 `sin(uv.y * _ScanlineDensity * PI)` 与伪随机行跳动噪声（Simplex Noise）；
  * 颜色通道分离（Chromatic Aberration）：RGB分量做极细微的UV水平位移（-0.003, 0.0, +0.003），营造老显像管色散感。

### 3. `UI_AnalogGaugeNeedle.cs` (机械动圈表头指针驱动器)
* **物理惯性公式：** 拒绝简单的线性插值 `Mathf.Lerp`，采用带阻尼的二阶弹簧振荡算法（Spring-Damper Simulation）：
  ```csharp
  float force = (targetAngle - currentAngle) * springStiffness;
  velocity = (velocity + force * deltaTime) * damping;
  currentAngle += velocity * deltaTime;
  ```
  在武器爆发或受击时，指针能展现真实的物理超调（Overshoot）与轻微回弹颤动。

## 总结：本UI设计达成的体验目标
1. **彻底消除“页游/手游感”：** 所有UI交互均有物理承载物（收音机、仪表、真空管、纸张手账、印字标签带）。
2. **玩法与背景100%咬合：** 经验条是调频旋钮，血条是接地电平水银管，三选一是捕捉反抗电台，死亡是显像管断电与磁带倒带。
3. **极佳的可读性与沉浸感平衡：** 关键信息（血量、技能CD、击杀反馈）通过发光与高反差物理表头清晰传递，不干扰俯视角3D割草的战斗爽感，同时在暂停与升级时提供浓厚的叙事浸润。
