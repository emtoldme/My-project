# 光照与阴影回退修复 R9

2026-10-14。用户反馈 R8 的光照明显丢失，阴影仍闪烁，画面更差。本轮以正式 Main 的可见表现为准，恢复光影，并保留共享实体麦田的内存优化。分支 `fix/lighting-shadow-r9`，接续 `perf/ground-light-props-r8`。没有增加玩法规则。

## 修复内容

- 恢复 R7 的黄昏主光强度、暖色环境补光、曝光与 Bloom；主光恢复 4096 阴影图、4 级级联、65 米阴影距离和高质量软阴影。
- 从 Main 移除每 0.16 秒重新排名、最多开启 8 盏灯的 SceneLightBudget。农机、路灯与旧物的真实灯光继续由天气和叙事状态决定，避免按距离突然熄灭。
- 环境遮蔽恢复原分辨率、高采样与高质量深度法线重建，并改用固定的 InterleavedGradient 采样。原来的低采样 BlueNoise 每帧更换噪声，而当前 SMAA 不进行时间累积，容易产生暗部抖动。保持 AfterOpaque=false，与正式渲染路径兼容。
- 麦田取消 25 米硬投影截止。可见模型不再直接投影，另用原始完整实体麦秆、相同风和接触变形，只渲染阴影。投影密度与形状不随可见模型的细节级别切换；阴影距离淡出交给 URP。
- 按太阳的实际方向，把画外麦秆的地面投影范围纳入剔除判断，避免镜头边缘的麦秆突然带走路面阴影。原生主光也取消额外的视锥灯光裁剪。
- 完整近景模型范围恢复到 32 米，退出使用 36 米迟滞；中景退出 56 米、返回 52 米。共享源模型仍只有 12 个、合计 2764 顶点，49 块驻留与回收机制保留。
- 全部麦田细节级别都接受真实局部光和透射光；远景仍减少表面微细节。激活灯光的体积积分恢复 16 步。闲置广播结构仍按既有状态保持克制亮度。

## 验证边界

只验证本轮灯光、麦田投影与相关 Shader：正式 Main 实际出发，晴/雨/雷雨转换，场景灯的像素贡献，画外投影，暂停后的连续帧，以及移动镜头与可见模型切换。相机截图通过正式 URP 渲染请求生成，麦田使用实际 GPU 实例提交。

最终源码的 Main 检查通过前 15 项。局部灯关闭对照在相机中产生约 0.00282 的归一化 RGB 平均差，确认恢复的灯具参与实际照明。冻结天气/风的 12 张连续镜头平移截图和投影提交量保存在 `rain-pan-*.png` 与 `pan-casters.csv`。它们用于检查大块阴影缺失，不构成所有视角都无亚像素闪烁的保证。

第一次额外路面检查把胶片颗粒和输出抖动算进了阴影变化，平均差约 0.00195，未通过严格阈值。保留该失败日志；随后只复验这一项，在诊断进程中关闭胶片颗粒、输出抖动和半透明雨雾，保留正式光照、环境遮蔽和阴影路径。正式 Main 出发与路面复验 2 项通过：8 个独立原生帧中，1600×900 图像的中心下方 800×440 区域平均绝对 RGB 差为 0。正常试玩包保留胶片颗粒与雨雾，不能把诊断结果解释为正常雨天整张画面完全不变化。

证据目录：根目录 `Reviews/LightingRepairR9-2026-10-14`。`Initial` 保留第一次检查；顶层场景图片与 `review-final.log` 对应扩大近景模型范围后的检查；`road-final.log`、`road-static-shadow-delta.txt` 和 `road-rain-*.png` 对应排除颗粒噪声后的路面复验。所有临时设置只作用于验证进程；验证工具归档在该目录的 `Tools`，不进入游戏运行时。

R8 的耗时数字不能代表本轮版本；恢复灯光、完整投影和近景模型会增加绘制开销。本轮没有重跑全量性能矩阵，也不据此宣称最终画质达标或保证固定帧率。
