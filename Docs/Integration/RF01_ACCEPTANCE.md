# RF01 麦田战斗样板验收

2026-10-12。四位外部 AI 的 TASKS_04/05 由 Codex 集中整合；本轮先验收实机样板，不启动完整关卡与正式角色制作。

## 打开与操作

工作区 `Builds/RF01-RyeField/打开游戏.cmd` 默认桌面全屏；`窗口模式.cmd` 以 1280×720 打开。F11 随时切换，暂停时也有效。WASD 移动、自动攻击、Space 闪避、Esc 暂停；面板切换 None / Echo / Propagation / Combined 会同种子重开。建议先 Combined，再与 None / Echo 对比。

## 本轮看什么

1. **环境质感**：三种地表组成小路、干土与外围麦秸，200 高麦丛与 20 低植被。观察正常游戏镜头下是否仍像塑料、贴图是否太重复、麦田是否太稀，以及战斗空地是否过分空。先验收质感方向，不要求把小样板当完整地图。
2. **攻击因果**：普通命中是小暖色闪击；紫红菱形在原目标身上收束，真实回声命中才出现“回声 -5”；金黄连线指向实际受到传播伤害的目标，并出现伤害数字。判断是否能看懂“等一下再伤原目标”和“传到另一目标”，以及字是否太小或遮挡。
3. **听觉区分**：回声预备保持静默，成功回声是低沉短共鸣，传播是短扫频。先听 Echo 再听 Combined，判断能否区分直接命中/回声/传播、组合是否太吵或太轻。不必再次确认已肯定的闪避与组合方向。

回复可直接用：`环境：……；回声/传播：……；声音：……`。同时留意中文飘字和面板是否正常、F11 是否适合屏幕。

## 如实保留的阶段限制

- 主角、敌人仍使用旧 TEST_ONLY 临时模型。提交的角色 .blend 是 WIP，尚未作为可用骨骼动画角色导入。
- 旧式调频器按原尺寸摆在场景旁作材质展示，没有持枪挂点与开火动画；开火 VFX 从当前临时玩家发出。
- 这是 24m×24m 环境样板，外围使用同一48m地形的干土过渡延续，尚非完整地图。高麦丛只出现在中心约 6m 以外，不能据此保证玩家走进麦田后无遮挡。
- LOD1 仍有原模型高度差，样板强制 LOD0；未修改源网格。
- 音效仍 TEST_ONLY，本轮没有新增正式 BGM；短时自动检查不能代替实际监听、最终美术验收或发布性能认证。
