# S2-01 联合视听样板：共用契约

2026-10-12。用户反馈当前试玩“一切正常”，并授权下一步协作。S1可玩基线保留，进入S2首个样板制作；不把这次授权记成最终美术、音乐或S2验收通过。

## 本轮唯一目标

同一个真实游戏镜头中，做出30—60秒可玩的“会共振的雕塑”样板：普通攻击/命中、手动闪避、拾取、升级三选一及一次已有精英击杀强调。若精英接入存在问题先交复现，不新增Boss或进化机制凑演示。保留已有3分钟局长与玩法数值，不扩充武器、永久成长或新状态机。

沿用Unity6000.4.3f1、URP、GameLoop → RunSimulation → RunState、GameInput、CombatViews、VfxDirector、AudioDirector及PresentationDispatched。画面适配只读规则，不借动画改伤害、碰撞、移动、闪避无敌或冷却。

## 统一的制作语言

- 形体：偏心、开缝、分节，明确朝向和干净倒角；不继续深化临时工业机甲。
- 材质：细腻哑光陶瓷/涂层为主，少量半哑光金属和局部发光。URP Lit起步，先靠比例、倒角、光照和阴影成立，不依赖大Bloom或复杂Shader。
- 动作：即时响应 → 短收束/错位展开 → 复位。真正输入与攻击不等待音乐节拍。
- 声音：短干敲击、拨弦/金属片共鸣、克制电子脉冲；普通事件短而让位，强事件才展开尾音。数学摇滚是错位器乐结构，后摇提供空间发展，电子提供骨架。
- 第一版色彩语义提案：环境冷灰、玩家瓷白/少量钴蓝、敌人石墨灰、敌方危险朱橙、经验暖金。数值和强度通过样板判断，不宣称用户已批准具体色卡。
- 保留当前正交Size9、Pitch55/Yaw45与闪避修复；镜头/比例如需变化先在独立样板参数中提出比较。

## 资产与动作约定

1 Unity单位=1米，Y向上、+Z为前方；根节点比例(1,1,1)，轴心在脚底中心。玩家高度约1.8米、敌人约1.3—1.5米；不把FBX的100倍缩放传给表现代码。

建议玩家Prefab名RS_Player，敌人RS_Enemy。2号在现有玩家的Visual下放模型，模型内用MotionRoot承载表现偏移，Core/Segment_A/Segment_B表达主体与分节。几何节点名称不承担玩法规则。共享CombatViews仍控制Visual朝向，局部动效只写MotionRoot/分节，回池和重开恢复初始值。

素材交接必须列实际文件、尺寸、轴向、材质、节点/挂点、来源、生成方法与缺项。可交FBX/OBJ或可一键生成持久Mesh/Prefab的Unity Editor工具；纯概念图和报告不能替代可导入模型。单张平面效果图也不能声称实际引擎运行。

多个静态Mesh组成的新玩家需要完整残影快照；现有VfxDirector的静态备选只取一个MeshFilter。该共享修改归Codex，2号交模型结构和复现/接口需求，不另建残影管理器，也不要复制整份VfxDirector。

## 事件和时间

只使用PresentationEventType：Shot、EnemyHit、EnemyKilled、PlayerHurt、Dodge、GemPickup、LevelUpShown、LevelUpChosen、Paused、Resumed、Victory、Defeat、Restart。位置取事件XZ；池视图/身份读现有CombatModule，不根据动画再次结算。

世界动效采用实际逻辑dt，只在Playing推进；暂停/升级/终局冻结并按原语义清理。升级UI动画用unscaled时间，暂停须停止非必要循环。音乐过渡在LevelUp仍可推进，Paused冻结；组件重启读取RunState，不能把音频组件启用当成游戏新开局。

一个语义事件只保留一处音频入口和一处同类FX入口。新样板若替换某类表现，需禁用/配置原表现并在交接标明，不能叠加两套射击声、两套升级面板或两套闪避残影。正式资源接入和旧视图替换由Codex最终核对。

## 初期验收

每位只做本轮必要编译/关键路径。没有Unity就如实写未编译，由Codex导入、生成.meta和运行；不要让用户补环境、搬文件或跑测试。不要为了小样执行全设备、200敌人长时压力或每个PR重新打包。

本轮交付顺序：资产/声音小样 → 2号装配 → Codex整合与短检查 → 一个Windows试玩包/同机位画面/简短试听材料 → 用户判断形体、哑光质感、爆发强度、音乐比例与整体辨识度。S2通过后才批量填充内容。

本文件只定义当前已授权样板；审美上限不能靠“对标主流”文字验收，也不因各AI提交完毕就自动通过。
