# C-01B 接线与S1试玩说明

C-01A来源：PR #9，81b1d66e924fd6979875156fd86d386a34b54b7f；基线main b6df1fd。C-01B由Codex在独立工作目录开发，不改写1号的原分支，也不修改2号当前负责的Views/Audio。

## 接线

GameLoop每局为RunSimulation传入CombatConfig，新建CombatModule。主循环T3运行StepCombat并复制事件；T8统一处理最大接触伤害/可选叠加与无敌；T9判失败跳过宝石；T10拾取经验；所有执行战斗的结束路径T13释放。Frame由主循环补齐，表现事件沿用唯一通道。

原框架的只读测试可不传CombatConfig，继续单独验证状态机；正式GameLoop始终创建战斗模块，新增接线用例明确覆盖实际组合。RunConfig的时长、场地范围、宝石寿命为游戏配置入口，开局同步到模块；武器升级属性每帧传入。

CombatViews按PoolIndex预热和同步敌人/子弹/宝石，不参与玩法判定；活跃对象不每帧重启。普通敌人沿用一种模型，阶段用颜色区分，精英只调大小/强调色。支持敌人受击闪白、弹丸、经验旋转/浮动与到期闪烁；现有VFX/音效读取同一战斗事件。玩家比例与脚底位置自动归一化，青色脚底环指示真实位置，避免临时模型体积掩盖判定。

闪避初值：锁定发动时的移动方向；无方向用最后移动方向，首次用相机前方。0.2秒移动3米，期间无敌；冷却1.5秒，可升级；按下到冷却结束有0.1秒缓冲。暂停冻结逻辑与正在进行的闪避，离开Playing清掉尚未发动的输入缓冲。它是样板初值，手感待用户判断。

相机视野半径由实际四角视锥与地面交点计算，含分辨率宽高比。调试支持spawn n、spawngems n、setcap n；正式试玩默认隐藏调试，F1切换。

## 试玩

最新闪避修复Windows包：工作区Builds/S1-DodgeFix/Waffle.exe。旧Builds/S1-C01/Waffle.exe保留。双击启动，不需要Unity。修复原因、自动验证与实际渲染对照见Docs/Verification/DodgeFix/。
WASD移动，Space闪避，自动选敌攻击；Esc暂停；升级时1/2/3或鼠标选择；面板按钮重开。

请先玩约3分钟，只反馈：
1. 移动/闪避是否顺手，有无卡住、方向异常、暂停后补动作。
2. 玩家、敌人、子弹、经验是否易分辨；镜头是否舒服，危险接近是否看得清。
3. 射击、受击、拾取和音乐是否刺耳、过密或风格不协调。
4. 整体更希望保留或改变什么，以及S1通过/修正后再看。

无需运行测试、手工生成场景或.meta，也无需录制长视频。出现问题时提供简短触发步骤；方便时附截图即可。自动检查由Codex完成。当前是玩法灰盒，工业机甲只是临时素材，最终抽象几何与克制PBR方向仍待视觉样板验收。
